조말론을 사려고 하면 **용량에서 한 번 막힙니다.** 같은 향인데 가격이 꽤 차이나거든요.

저는 세 가지를 다 써봤습니다.

```
잉글리시 페어 앤 프리지아   100ml
블랙베리 앤 베이            50ml   (다 썼습니다)
우드 세이지 앤 씨 솔트       30ml
```

**우연히 그렇게 된 건 아닙니다.** 어느 향수를 얼마나 쓸지에 따라 용량을 다르게 샀고, 결과적으로 **그 선택이 맞았는지도 확인할 수 있었습니다.** 그 얘기를 적습니다.

## 병 크기가 생각보다 많이 다릅니다

숫자만 보면 30ml와 100ml가 3배 차이인데, **실물은 모양 자체가 다릅니다.**

```
100ml   넓고 각진 병       책상에 두면 존재감이 있음
50ml    100ml 과 같은 형태   비율만 작아짐
30ml    길고 좁은 병        가방에 들어감
```

**30ml만 형태가 다릅니다.** 폭이 좁아서 파우치나 가방에 넣기 좋고, 대신 **책상에 세워두면 덜 예쁩니다.** 조말론을 인테리어처럼 두고 쓰는 분들이 100ml를 고르는 이유가 있습니다.

> 라벨 테두리 색이 다른 건 용량 때문이 아니라 **제품 라인 차이**입니다. → [향수 이름 읽는 법](/blog/perfume-labels/)

## 얼마나 쓸 수 있나

1회 분사량은 보통 **0.1ml 안팎**입니다. 하루 2회 기준으로 계산하면 이렇습니다.

| 용량 | 매일 쓸 때 | **2\~3일에 한 번** |
| --- | --- | --- |
| 30ml | 약 5개월 | 약 1년 |
| 50ml | 약 8개월 | **약 2년** |
| 100ml | 약 1년 4개월 | **약 4년** |

여기서 중요한 숫자가 하나 있습니다.

> **향수는 개봉 후 1\~3년이면 변질되기 시작합니다.**

표와 겹쳐 보면 문제가 보입니다. **100ml를 매일 쓰지 않으면 다 쓰기 전에 변질됩니다.** → [향수 보관법과 유통기한](/blog/perfume-storage/)

## 세 용량을 써보고 알게 된 것

### ① 100ml는 "매일 쓸 향수"에만 맞습니다

제 100ml는 **잉글리시 페어 앤 프리지아**입니다. 셋 중 가장 자주 뿌리고, **옷에 뿌리는 기본값**이기도 해서 소비가 빠릅니다.

**이 향수라서 100ml가 맞았습니다.** 만약 우드 세이지를 100ml로 샀다면 지금쯤 한참 남아 있었을 겁니다.

```
100ml 를 살 자격   →  "이건 거의 매일 쓸 것 같다" 는 확신
```

**그 확신은 써봐야 생깁니다.** 그래서 처음 사는 향수를 100ml로 가는 건 순서가 뒤바뀐 선택입니다.

### ② 50ml는 다 쓸 수 있는 양이었습니다

**블랙베리 앤 베이 50ml를 끝까지 썼습니다.** 지금 가진 향수 중 다 쓴 건 이게 유일합니다.

매일 뿌리는 향수가 아니었는데도 다 썼습니다. 그리고 **마지막까지 질리지 않았습니다.** → [블랙베리 앤 베이 리뷰](/blog/jo-malone-blackberry-bay/)

**50ml가 가장 균형이 좋은 용량**인 것 같습니다. 매일 안 써도 변질 전에 비울 수 있고, 가격 부담도 100ml보다 훨씬 가볍습니다.

### ③ 30ml는 "확신이 없을 때"의 답입니다

우드 세이지는 **호불호가 갈릴 수 있는 향**입니다. 바닷가의 허브 같은 인상이라서요.

**그래서 30ml로 샀고, 그게 맞았습니다.** 좋아하긴 하지만 **잘 보이고 싶은 날**에만 꺼내다 보니 소비가 느립니다. 100ml였다면 몇 년이 걸렸을 겁니다.

→ [우드 세이지 앤 씨 솔트 리뷰](/blog/jo-malone-wood-sage-sea-salt/)

## 큰 병이 이득인가

1ml당 단가만 보면 **큰 쪽이 확실히 쌉니다.** 조말론도 마찬가지고요.

```
용량이 3배인데   가격은 3배가 안 됨
```

**그런데 다 못 쓰면 이 계산은 무의미합니다.** 절반을 버리면 1ml당 단가는 두 배가 됩니다. 표기 가격이 아니라 **실제로 쓴 양 기준**으로 계산해야 합니다.

| | 표기 단가 | 절반만 썼을 때 |
| --- | --- | --- |
| 30ml | 비쌈 | 비쌈 |
| 100ml | **쌈** | **30ml 보다 비싸짐** |

**그리고 병이 여러 개면 이 위험이 커집니다.** 번갈아 쓰면 한 병당 소비 속도가 나눠지거든요. 저도 지금 네 병을 돌려 쓰는 중이라 소비가 느립니다. → [향수 몇 병이 적당한가](/blog/how-many-perfumes/)

## 그래서 — 이렇게 고르세요

| 상황 | 용량 |
| --- | --- |
| **처음 사는 조말론** | **30ml** |
| 호불호가 갈릴 향 (우드 세이지 등) | **30ml** |
| 데일리로 쓸 것 같은 향 | **50ml** |
| 이미 써봤고 매일 쓴다는 확신이 있음 | 100ml |
| 선물 | 30\~50ml |
| 여행·휴대 | 30ml (병이 좁습니다) |

**확신이 없으면 작게 사는 게 거의 항상 맞습니다.** 좋으면 다음에 큰 걸 사면 되고, 안 맞으면 손실이 작습니다.

### 더 싸게 확인하는 방법

용량을 고르기 전에 **소분으로 먼저 써보는 것**이 가장 쌉니다.

```
디캔트 3~5ml   →  며칠 실제 생활에서 착용
좋으면          →  30ml 또는 50ml
```

매장에서 맡는 건 **15\~30분이면 사라질 탑 노트뿐**입니다. 조말론 콜로뉴는 특히 전개가 단순해서, **며칠 써봐야 질리는지 아닌지를 알 수 있습니다.** → [디캔트 완전정리](/blog/decant-guide/)

## 정리

```
30ml   확신이 없을 때 · 호불호 갈리는 향 · 휴대용      병이 길고 좁음
50ml   가장 균형이 좋음 · 다 쓸 수 있는 양            100ml 과 같은 형태
100ml  거의 매일 쓴다는 확신이 있을 때만              넓고 각진 병
```

세 용량을 다 써보고 내린 결론은 단순합니다. **용량은 향을 얼마나 좋아하느냐가 아니라, 얼마나 자주 쓸 것 같으냐로 정해야 합니다.**

제가 가장 좋아하는 향은 셋 다인데, **100ml를 산 건 가장 자주 쓸 향수 하나뿐**입니다. 그 선택은 지금도 맞았다고 생각합니다.

**그리고 다 쓴 건 50ml 하나입니다.** 큰 병이 이득인지 아닌지는, 비우고 나서야 알 수 있습니다.
