**10월쯤 되면 쓰던 향수가 갑자기 심심해집니다.**

여름 내내 좋았던 시트러스가 밍밍하게 느껴지고, 뿌려도 뿌린 것 같지가 않습니다. 향수가 변한 게 아니라 **기온이 바뀐 겁니다.**

가을에 향수를 다시 고르게 되는 이유와, 무엇을 기준으로 고르면 되는지 정리했습니다.

## 왜 가을이면 향이 약해지나

**향료는 열로 피어오릅니다.** 알코올이 증발하면서 향 분자를 공기 중으로 밀어 올리는데, 이 과정이 온도에 직접 영향을 받습니다.

```
기온 30도   향이 빠르게 퍼짐 · 강하게 느껴짐 · 빨리 사라짐
기온 15도   천천히 퍼짐 · 약하게 느껴짐 · 오래 남음
```

즉 **가을엔 같은 향수가 "약하지만 오래가는" 쪽으로 바뀝니다.**

여기에 옷이 더해집니다. 여름엔 피부가 많이 드러나 향이 바로 퍼지지만, 가을엔 니트와 재킷이 향을 가둡니다. **체감 확산력이 눈에 띄게 떨어집니다.**

계절 전체의 원리는 [계절별 향수 선택법](/blog/seasonal-fragrance/)에 정리해 뒀습니다.

## 가을에 할 수 있는 선택은 두 가지

### ① 쓰던 향수를 더 뿌린다

가장 간단합니다. 여름에 2회 뿌리던 걸 **3회로 늘리면** 체감이 비슷해집니다.

**다만 한계가 있습니다.** 시트러스 계열은 애초에 지속력이 1\~3시간이라, 양을 늘려도 오래가진 않습니다. 더 강해질 뿐 더 길어지진 않습니다.

### ② 계열을 바꾼다

**가을·겨울이 향수를 한 병 더 들이기 가장 좋은 시기인 이유**입니다. 여름엔 과하게 느껴지던 계열이 이 시기엔 제대로 맞습니다.

## 가을에 맞는 계열

| 계열 | 가을에 좋은 이유 |
| --- | --- |
| **우디** | 건조하고 따뜻합니다. 가장 안전한 선택 |
| **앰버(오리엔탈)** | 묵직하고 달큰합니다. 추워질수록 제값을 함 |
| **스파이시** | 계피·후추·카다멈. 체온과 잘 맞습니다 |
| **구르망** | 바닐라·통카빈. 호불호는 갈립니다 |
| 푸제르 | 사계절용이지만 가을에도 무난합니다 |
| 시트러스 | 쓸 수 있지만 **존재감이 약해집니다** |

계열별 특징은 [향 계열 8가지 정리](/blog/fragrance-families/)에 자세히 적었습니다.

**처음 가을 향수를 고른다면 우디를 권합니다.** 앰버와 구르망은 존재감이 강해서 양 조절에 실패하면 사고가 납니다. 우디는 과해도 덜 불쾌합니다.

## 가을 향수 고르는 네 가지 기준

**① 베이스에 나무가 들어가 있는가**

샌달우드, 시더우드, 베티버, 파촐리 — 이 단어가 베이스에 있으면 가을에 잘 맞습니다. **노트표를 베이스부터 읽는 습관**이 여기서도 유효합니다. → [잔향이 좋은 향수 고르는 법](/blog/drydown-guide/)

**② 여름에 "과하다"고 느꼈던 향수인가**

이게 실용적인 신호입니다. 여름에 부담스러웠던 향수를 가을에 다시 뿌려보면 **딱 맞는 경우가 많습니다.** 새로 사기 전에 가진 것부터 다시 꺼내보세요.

**③ 지속력이 충분한가**

가을은 옷과 실내외 온도차 때문에 향이 들쭉날쭉합니다. **지속력에 여유가 있는 쪽**이 편합니다. EDT 이상을 권합니다. → [향수 부향률 완전정리](/blog/perfume-concentration/)

**④ 실내에서도 괜찮은가**

놓치기 쉬운 부분입니다. 가을·겨울엔 **실내에 머무는 시간이 길어집니다.** 난방이 들어온 실내는 체감상 여름과 비슷하게 향이 퍼집니다.

```
밖에서 적당하게 뿌린 양  →  난방 들어온 실내에서 과해짐
```

## 실제로 가을에 꺼내는 향수

제가 가진 다섯 병 중 **가을용으로 확실한 건 하나**입니다.

**존 바바토스 아티산** — 공식 계열은 시트러스 아로마틱인데, 제 피부에서는 **잔향에서 나무 느낌이 올라옵니다.** 그 구간이 가을과 맞습니다.

여름엔 첫 향이 더 부담스럽게 느껴지는데, 날이 선선해지면 그 진함이 과하게 느껴지지 않습니다. **같은 향수가 계절에 따라 평가가 달라지는 사례**입니다. → [존 바바토스 아티산 리뷰](/blog/john-varvatos-artisan/)

반면 **조말론 콜로뉴 3종은 가을에 존재감이 확 줄어듭니다.** 원래 농도가 낮은 데다 옷이 두꺼워지니 체감이 더 약해집니다. 못 쓸 정도는 아니지만 **한 번 더 뿌려야 합니다.** → [조말론 3종 비교](/blog/jo-malone-comparison/)

```
가을에 올라오는 향수   우디·앰버 베이스
가을에 묻히는 향수     가벼운 콜로뉴·시트러스
```

## 새로 사기 전에 — 확인할 것

**가을 향수를 산다고 할 때 가장 흔한 실수**는 매장에서 결정하는 겁니다.

가을 계열(우디·앰버·스파이시)은 **첫 향과 끝이 특히 많이 다릅니다.** 매장에서 맡는 15분으로는 판단이 안 됩니다. 실제로 제가 가진 아티산도 매장에서 맡았다면 안 샀을 향수입니다.

```
① 시향지로 후보 추리기
② 피부에 2개까지만
③ 나가서 1시간 뒤 판단
④ 가능하면 소분으로 며칠
```

→ [향수 시향 제대로 하는 법](/blog/how-to-test-fragrance/) · [디캔트 완전정리](/blog/decant-guide/)

그리고 **가격대가 올라가는 계열**이라는 점도 알아두면 좋습니다. 우디·앰버 쪽은 디자이너 라인에도 좋은 선택지가 많으니, 비싼 쪽부터 볼 필요는 없습니다. → [니치 향수와 디자이너 향수는 뭐가 다른가](/blog/niche-vs-designer/)

## 정리

**가을에 향수가 약해지는 건 향수 문제가 아니라 기온 문제입니다.**

```
① 쓰던 걸 한 번 더 뿌린다        가장 쉬운 해결
② 여름에 과했던 향수를 다시 꺼낸다  돈이 안 듦
③ 그래도 아쉬우면 우디 계열을 하나  가장 안전한 추가
```

순서가 중요합니다. **②를 건너뛰고 ③으로 가는 사람이 많은데**, 가진 향수 중에 가을용이 이미 있을 가능성이 꽤 높습니다.

그리고 실내가 길어지는 계절입니다. **바깥 기준으로 뿌리면 과해집니다.** 한 번 줄이세요.
