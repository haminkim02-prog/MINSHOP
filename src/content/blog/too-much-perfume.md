**뿌리고 나서 "아, 많다" 싶은 순간**이 있습니다.

손이 미끄러졌거나, 병을 바꿨는데 분사량이 달랐거나, 그날따라 코가 둔했거나.

**나가기 5분 전이면 선택지가 별로 없습니다.** 그래서 **그 5분 안에 할 수 있는 것**부터 순서대로 정리했습니다.

---

## 먼저 — 물로 씻으면 더 나빠집니다

**가장 먼저 떠오르는 방법인데, 역효과입니다.**

향료는 **기름에 녹는 성분**입니다. 물에는 잘 안 녹습니다. 물로 씻으면 **알코올만 먼저 씻겨나가고 향료는 남습니다.**

```
알코올이 먼저 날아감  →  향은 그대로
물까지 더해짐         →  피부가 젖어서 발향이 오히려 강해집니다
```

게다가 **젖은 피부는 체온이 전달되면서 향이 더 올라옵니다.** 줄이려다 키우는 셈입니다.

**비누로 문질러 씻으면** 어느 정도 빠지지만, **5분 안에 할 수 있는 일은 아니고** 피부도 상합니다.

---

## 실제로 통하는 순서

**위에서부터 하세요. 아래로 갈수록 시간이 더 듭니다.**

### ① 알코올 솜으로 닦기 — 가장 빠릅니다

**향료는 알코올에 녹습니다.** 소독용 알코올 솜이나 손 소독제를 솜·휴지에 묻혀 **뿌린 자리를 가볍게 닦으면** 상당량이 걷힙니다.

```
걸리는 시간   →  30초
효과          →  절반 이상 줄어듭니다
주의          →  문지르지 말고 눌러서 닦으세요
```

**문지르면 향이 퍼집니다.** 누르고 떼기를 반복하세요.

피부가 예민하면 알코올이 자극이 될 수 있으니, **얼굴 가까이나 상처 부위는 피하세요.**

### ② 무향 로션이나 바디오일로 덮어 닦기

알코올이 없으면 **기름으로 녹여서 닦아내는 방법**이 있습니다.

로션을 바르고 **휴지로 닦아내면** 향료가 로션에 섞여 나옵니다. 한 번에 다 빠지진 않지만 **두세 번 반복하면 꽤 줄어듭니다.**

**무향 제품**이어야 합니다. 향이 있는 로션이면 **냄새 두 개를 겹치는 셈**입니다.

### ③ 옷을 바꾸거나 벗기

**옷에 뿌렸다면 그게 주범입니다.**

피부에 뿌린 향은 몇 시간이면 줄지만, **섬유에 붙은 향은 하루 이상 갑니다.** 겉옷에 뿌렸다면 **그 겉옷만 바꿔 입어도** 체감이 크게 달라집니다.

```
피부    →  시간이 지나면 줄어듭니다
섬유    →  안 줄어듭니다. 빼는 수밖에 없습니다
```

### ④ 바람을 쐬기

**가장 소극적이지만 아무것도 안 하는 것보단 낫습니다.**

**뿌린 직후일수록 효과가 큽니다.** 알코올과 탑노트가 날아가는 구간이라, 창문 앞이나 밖에서 **2\~3분 바람을 맞으면** 초반 강도가 눈에 띄게 꺾입니다.

손목이라면 **팔을 흔드는 것만으로도** 공기 접촉이 늘어납니다.

---

## 상황별로 어디까지 할지

**전부 다 할 필요는 없습니다.**

| 상황 | 권하는 것 |
| --- | --- |
| 혼자 있는 날 | **④만.** 몇 시간이면 줄어듭니다 |
| 출근·외출 | **①** 후 바람 쐬기 |
| 면접·좁은 회의실 | **① + ③.** 옷까지 바꾸세요 |
| 병원·장례식장 | **① + ③ + 시간을 늦추세요** |

**면접이나 경조사라면 과한 향은 실제로 감점 요인**입니다. 그 상황이면 **5분 늦더라도 제대로 걷어내고 가는 게 낫습니다.**

---

## 왜 자꾸 많이 뿌리게 되나

**원인을 알면 반복이 줄어듭니다. 대개 셋 중 하나입니다.**

### ① 코가 적응했습니다

**가장 흔합니다.** 뿌린 지 20\~30분이 지나면 자기 향은 안 느껴집니다. 그래서 더 뿌립니다.

[따로 정리한 글](/blog/cant-smell-own-perfume/)이 있는데, **"안 느껴진다"는 감각을 기준으로 삼으면 거의 항상 과해집니다.**

### ② 병을 바꿨습니다

**분사량이 병마다 다릅니다.** 100ml 쓰다가 30ml로 넘어가면 같은 두 번이 다른 양입니다. 자세한 건 [분사량 글](/blog/spray-amount/)에 적어뒀습니다.

### ③ 계절이 바뀌었습니다

**추워지면 향이 덜 올라옵니다.** 그래서 겨울에 양을 늘리는데, **난방이 들어온 실내에 들어가는 순간 그 양이 과해집니다.**

겨울에 "밖에선 괜찮았는데 사무실에서 과했다"가 생기는 이유입니다.

---

## 예방 — 뿌리는 순서를 바꾸세요

**가장 확실한 건 과하게 뿌릴 수 없는 순서로 만드는 것**입니다.

```
① 옷 입기 전에 뿌리기        옷에 직접 안 묻습니다
② 한 번 뿌리고 10분 기다리기  필요하면 그때 추가
③ 공중에 뿌리고 걸어들어가기  양이 자동으로 줄어듭니다
```

**②가 핵심입니다.** 모자란 건 10분 뒤에 더하면 되지만, **많은 건 되돌리기 어렵습니다.**

③은 흔히 권해지는 방법인데, **옷 전체에 옅게 퍼지는 대신 향이 금방 날아갑니다.** 지속력을 포기하는 대가로 안전을 사는 선택입니다.

---

## 정리

```
① 물로 씻지 마세요            알코올만 빠지고 향은 남습니다
② 알코올 솜으로 눌러 닦기      30초, 가장 효과적
③ 옷이 범인이면 옷을 바꾸세요  섬유는 안 줄어듭니다
④ 다음부터는 한 번 → 10분 → 추가
```

**과하게 뿌리는 건 성격 문제가 아니라 감각 문제입니다.** 자기 향을 못 맡는 상태에서 판단하니까 매번 같은 방향으로 틀립니다.

그래서 **감각 대신 규칙을 쓰는 게** 결국 답이었습니다. 저는 **"한 번 뿌리고 10분"**으로 바꾸고 나서 이 상황이 거의 없어졌습니다.
