같은 향수인데 이름이 이렇게 여러 개입니다.

```
Sauvage
Sauvage Eau de Toilette
Sauvage Eau de Parfum
Sauvage Parfum
Sauvage Elixir
```

이게 다 다른 제품이고, **향도 서로 다릅니다.** 뒤에 붙은 단어를 읽을 수 있으면 사기 전에 어떤 물건인지 판단할 수 있습니다.

기본 개념인 부향률은 [향수 부향률 완전정리](/blog/perfume-concentration/)에 정리했으니, 이 글은 **라벨에 실제로 적히는 표기들**을 다룹니다.

## 1. 농도를 나타내는 표기

가장 기본이 되는 다섯 가지입니다.

| 표기 | 약자 | 부향률 | 대략적 지속력 |
| --- | --- | --- | --- |
| Eau Fraîche | — | 1~3% | 1시간 내외 |
| Eau de Cologne | EDC | 2~5% | 1~2시간 |
| Eau de Toilette | EDT | 5~15% | 3~5시간 |
| Eau de Parfum | EDP | 15~20% | 5~8시간 |
| Parfum / Extrait de Parfum | — | 20~40% | 8시간 이상 |

`Eau`는 프랑스어로 "물"입니다. `Eau de Toilette`는 직역하면 "화장(단장)의 물" 정도입니다.

**`Extrait de Parfum`**은 가장 진한 형태로, 그냥 `Extrait` 또는 `Parfum`이라고만 적히기도 합니다. 용량이 작고(보통 7.5~30ml) 가격이 높습니다.

## 2. ⚠️ 가장 중요한 사실 — 이 기준은 법이 아닙니다

여기가 이 글의 핵심입니다.

**부향률에는 국제적인 법적 규제가 없습니다.** 위 표는 업계 관행일 뿐이고, **각 브랜드가 자기 마음대로 이름을 붙입니다.**

그래서 이런 일이 실제로 벌어집니다.

- A 브랜드의 **EDT**가 B 브랜드의 **EDP**보다 더 진할 수 있습니다
- 어떤 브랜드는 EDT를 12%로 만들고, 어떤 브랜드는 6%로 만듭니다
- 같은 브랜드 안에서도 라인마다 기준이 다를 수 있습니다

**결론: EDP라고 무조건 오래가는 게 아닙니다.** 표기는 참고만 하고, 실제 지속력은 시향이나 리뷰로 확인해야 합니다. 이 블로그의 리뷰에 1·3·6·9시간 실측을 넣는 이유가 이것입니다.

## 3. 브랜드가 붙이는 수식어

농도 표기와 별개로, 브랜드가 마케팅을 위해 붙이는 단어들입니다. **이쪽은 기준이 더 없습니다.**

| 표기 | 보통 의미하는 것 |
| --- | --- |
| **Intense** | 원작보다 진하거나 무겁게 재조합 |
| **Extreme / Extrême** | Intense와 비슷. 더 강조된 버전 |
| **Elixir** | 최근 유행하는 이름. 대개 EDP 이상의 농도 + 스파이시·앰버 강화 |
| **Absolu** | 진한 버전. 원료를 더 넣었다는 인상 |
| **Concentré** | 농축. EDT를 진하게 만든 버전 |
| **Le Parfum** | "그 향수"라는 뜻이지만, 실제 농도는 브랜드마다 다름 |
| **Eau / Eau Fraîche** | 원작을 가볍게 만든 버전 |
| **Sport** | 가볍고 상쾌하게. 시트러스·아쿠아틱 강화 |
| **Nuit / Noir** | 밤. 어둡고 무거운 방향 |
| **Blanc / Blanche** | 밝고 깨끗한 방향 |

**주의할 점:** `Intense`나 `Elixir`가 붙었다고 해서 **원작을 그냥 진하게 만든 게 아닙니다.** 대부분 **조합 자체를 다시 짠 별개의 향수**입니다. 원작을 좋아해서 Intense를 샀는데 전혀 다른 향이라 실망하는 경우가 흔합니다.

## 4. 플랭커(Flanker)라는 개념

원작이 성공하면 브랜드는 파생 제품을 계속 냅니다. 이걸 **플랭커(flanker)**라고 부릅니다.

```
원작:    Sauvage EDT
플랭커:  Sauvage EDP
         Sauvage Parfum
         Sauvage Elixir
```

플랭커는 원작의 이름값을 쓰지만 **향은 별개**입니다. 원작이 마음에 들었다면 플랭커도 반드시 따로 시향하세요.

플랭커가 많은 라인은 이름이 복잡해져서 구매할 때 혼동이 생깁니다. **정확한 제품명을 끝까지 확인**하는 습관이 필요합니다.

## 5. 리포뮬레이션 — 같은 이름, 다른 향

이건 알아두면 중고 거래나 오래된 재고를 살 때 도움이 됩니다.

향수는 출시 후에도 배합이 바뀝니다. 이유는 두 가지입니다.

- **IFRA 규제** — 국제향료협회가 안전성을 이유로 특정 원료의 사용량을 제한합니다. 오크모스와 일부 천연 무스크가 대표적입니다
- **원가 절감** — 비싼 천연 향료를 합성으로 대체

그래서 같은 이름의 향수도 **2010년 생산품과 2026년 생산품의 향이 다를 수 있습니다.** "옛날 그 향이 아니다"라는 말이 나오는 이유입니다.

제조 시기는 병 바닥이나 박스의 **배치 코드(batch code)**로 확인할 수 있습니다. 숫자·문자 조합이라 그대로는 못 읽지만, 배치 코드 조회 사이트에 입력하면 생산 시기가 나옵니다.

관련 내용은 [향수 보관법과 유통기한](/blog/perfume-storage/)에도 정리했습니다.

## 6. 그 외 라벨에서 보이는 것들

| 표기 | 뜻 |
| --- | --- |
| **Pour Homme** | 남성용 (프랑스어 "남자를 위한") |
| **Pour Femme** | 여성용 |
| **Unisex** | 남녀 공용 |
| **Natural Spray / Vaporisateur** | 분무형. 스프레이 |
| **Splash** | 뿌리는 게 아니라 따라 쓰는 형태 |
| **Tester** | 시향용으로 매장에 공급되는 제품. 내용물은 정품과 같고 박스·뚜껑이 간소합니다. 정품보다 저렴합니다 |
| **Miniature / Travel Size** | 소용량 (보통 5~15ml) |
| **Refill** | 리필용. 스프레이 없이 액체만 |

> **테스터(Tester)는 가짜가 아닙니다.** 내용물은 정품과 동일하고, 포장만 간소합니다. 정품보다 20~40% 저렴한 경우가 많아서, 향이 확실하다면 합리적인 선택입니다. 다만 뚜껑이 없거나 박스가 없어서 **보관에는 불리**합니다.

## 실전 — 라벨 읽는 순서

향수를 볼 때 이 순서로 확인하면 됩니다.

```
① 브랜드명            누가 만들었나
② 제품명              어떤 라인인가
③ 수식어              Intense / Elixir / Sport 등 → 원작과 다른 향
④ 농도 표기           EDT / EDP / Parfum → 대략의 진하기
⑤ 용량                50ml / 100ml
⑥ 1ml당 가격 환산     비교의 기준
```

**⑥이 특히 중요합니다.** 정가만 보면 비교가 안 됩니다.

```
EDT 100ml 12만원  →  1ml당 1,200원
EDP  50ml 11만원  →  1ml당 2,200원
```

EDP가 1ml당 거의 2배입니다. 다만 부향률이 높아 한 번에 적게 뿌려도 되니, 실사용 기준으로는 격차가 줄어듭니다.

## 정리

- `EDC < EDT < EDP < Parfum` 순으로 진해집니다
- **부향률에는 법적 규제가 없습니다.** 브랜드마다 기준이 다르니 표기를 절대적으로 믿지 마세요
- `Intense`, `Elixir`, `Absolu`는 진한 버전이 아니라 **조합이 다른 별개의 향수**입니다
- 플랭커는 원작과 향이 다릅니다. 반드시 따로 시향하세요
- 같은 이름도 생산 시기에 따라 향이 다를 수 있습니다 (리포뮬레이션)
- **테스터는 정품과 내용물이 같습니다.** 가격이 저렴한 합리적 선택입니다
- 가격은 **1ml당**으로 환산해서 비교하세요
