향수 실패를 줄이는 가장 확실한 방법은 **사기 전에 며칠 써보는 것**입니다.

그런데 매장에서는 그게 안 됩니다. 이 문제를 해결하는 게 **디캔트(decant)**입니다.

## 디캔트란

**큰 향수병에서 소량을 덜어 작은 용기에 담은 것**입니다. 우리말로는 소분이라고 합니다.

```
정품 100ml  →  3ml, 5ml, 10ml 단위로 나눠 담음
```

향수 자체는 **정품과 완전히 동일합니다.** 용기만 다릅니다.

| | 정품 50ml | 디캔트 5ml |
| --- | --- | --- |
| 가격 | 10\~20만원 | **3천\~1만원** |
| 내용물 | 동일 | 동일 |
| 용기 | 브랜드 유리병 | 소형 아토마이저 |
| 사용 기간 | 1\~3년 | 2\~4주 |

---

## 왜 디캔트를 써야 하나

### ① 매장 시향보다 정확합니다

매장에서는 **탑 노트만** 맡습니다. 그 향수의 본체는 30분 뒤부터 나옵니다. → [향수 노트란?](/blog/perfume-notes/)

디캔트로 며칠 써보면 이걸 전부 확인할 수 있습니다.

- 시간대별 향의 변화 (드라이다운까지)
- **실제 지속력** — 내 피부에서 몇 시간인지
- 주변 사람의 반응
- 출근·데이트 같은 **실제 상황에서의 적합성**
- 계절과 날씨에 따른 차이

### ② 실패 비용이 20분의 1입니다

```
정품을 잘못 사면      →  15만원 손실
디캔트를 잘못 사면    →  7천원 손실
```

**후보 3개를 디캔트로 검증해도 2\~3만원**입니다. 정품 하나 잘못 사는 것보다 훨씬 쌉니다.

### ③ 고가 향수를 경험할 수 있습니다

30만원짜리 니치 향수를 사기는 부담스럽지만, **5ml를 1만원대에 경험**할 수 있습니다. 취향을 넓히는 데 효과적입니다.

### ④ 여러 향수를 돌려쓸 수 있습니다

정품 한 병을 다 쓰려면 1\~2년이 걸립니다. 그동안 다른 향수를 못 씁니다.

디캔트 5개를 가지고 있으면 **기분과 상황에 따라 바꿔 쓸 수 있습니다.** 향수를 많이 경험하고 싶은 초반에 특히 좋습니다.

## 어디서 사나

**국내 온라인 소분샵**
- 네이버 스마트스토어, 쿠팡 등에서 "향수 소분", "디캔트"로 검색하면 전문 판매자가 많습니다
- 보통 **3ml / 5ml / 10ml** 단위
- 여러 개를 묶어 파는 **샘플러 세트**도 있습니다

**해외 사이트**
- 종류가 훨씬 많고 니치 브랜드 구성이 좋습니다
- 다만 배송이 오래 걸리고, 액체라 통관 이슈가 있을 수 있습니다

**브랜드 공식 샘플**
- 일부 브랜드는 공식몰에서 소용량 샘플 세트를 판매합니다
- 정품 구매 시 샘플을 주는 경우도 많으니 **매장에서 요청해 보세요**

---

## ⚠️ 디캔트 살 때 주의할 점

디캔트는 **재판매자가 직접 소분**하기 때문에, 판매자를 잘 골라야 합니다.

### 확인할 것

**① 정품 여부**
- 정품 원본 사진을 올려두는 판매자를 고르세요
- 배치 코드를 공개하면 더 좋습니다
- **비정상적으로 싼 곳은 피하세요**

**② 소분 용기의 품질**
- 저가 아토마이저는 **분사가 고르지 않고 새기도 합니다**
- 유리 재질이 플라스틱보다 향 보존에 유리합니다

**③ 소분 시점**
- 소분하면 공기에 노출되어 **정품보다 빨리 변질됩니다**
- 주문 후 소분해 보내주는 곳이 좋습니다

**④ 용량 표기**
- 실제 용량이 표기보다 적은 경우가 있습니다
- 후기를 확인하세요

### 디캔트의 한계

정직하게 말씀드리면 단점도 있습니다.

| 한계 | 설명 |
| --- | --- |
| **보관 기간이 짧다** | 공기 접촉이 많아 몇 달 내 쓰는 게 좋습니다 |
| **1ml당 단가는 비싸다** | 소분 수고비가 붙습니다. 검증용이지 상시 사용용이 아닙니다 |
| **분사 품질이 다르다** | 정품 스프레이보다 입자가 굵어 양 조절이 어려울 수 있습니다 |
| **판매자 신뢰도에 의존** | 정품 여부를 직접 확인할 수 없습니다 |

**그래서 디캔트는 "검증 도구"입니다.** 마음에 들면 정품을 사고, 아니면 버리는 용도로 쓰세요.

## 직접 소분하기

정품을 가지고 있는데 여행용으로 덜어 가고 싶다면 직접 할 수 있습니다.

**필요한 것**
- 소형 아토마이저 (5\~10ml, 몇 천 원)
- 스프레이 헤드가 분리되는 향수, 또는 소분 깔때기

**방법**
1. 아토마이저를 **완전히 건조**시킵니다 (물기가 남으면 향이 변합니다)
2. 향수 뚜껑을 열고 노즐을 아토마이저 입구에 대고 여러 번 분사하거나, 깔때기로 옮깁니다
3. 가득 채우지 말고 **80% 정도**만 (공기 여유 공간)

**주의**
- **비행기 기내 반입은 100ml 이하** 용기만 가능합니다 (액체류 규정 확인)
- 소분한 향수는 **원래 병보다 빨리 변질**되니 몇 주 안에 쓰세요

여행 시 큰 병을 들고 다니면 온도 변화로 향수가 상합니다. → [향수 보관법과 유통기한](/blog/perfume-storage/)

## 추천 활용법

```
① 매장에서 시향지로 후보 5개 → 2~3개로 좁히기        (무료)
② 그 2~3개를 디캔트로 구매                          (1~3만원)
③ 각각 3~4일씩 실제 생활에서 착용
④ 가장 좋았던 하나만 정품 구매                       (10~15만원)
```

이 흐름을 지키면 **실패한 정품이 거의 안 생깁니다.**

그리고 향수를 막 시작하는 단계라면, **정품을 사기 전에 디캔트로 5\~6개를 경험해 보는 것**을 권합니다. 취향이 훨씬 빨리 잡힙니다. → [향수 입문 로드맵](/blog/beginner-roadmap/)

## 정리

- 디캔트는 **정품을 소량으로 나눠 담은 것**입니다. 내용물은 같습니다
- 3\~5ml에 **3천\~1만원**. 정품 실패 비용의 20분의 1입니다
- **매장 시향보다 정확합니다.** 며칠 써보면 지속력과 드라이다운까지 확인됩니다
- 판매자의 **정품 여부와 용기 품질**을 확인하세요
- 보관 기간이 짧으니 **몇 주 안에** 쓰세요
- **검증 도구로 쓰고, 좋으면 정품을 사세요**

향수에 쓸 돈이 정해져 있다면, **그중 1\~2만원을 디캔트에 먼저 쓰는 것**이 가장 수익률 높은 지출입니다.
