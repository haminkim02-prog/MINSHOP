조말론을 쓰다 보면 **레이어링**이라는 말을 만나게 됩니다. 브랜드가 직접 권하는 사용법이기도 합니다.

보통은 **같은 자리에 두 개를 겹쳐 뿌리는 것**을 뜻합니다. 그런데 저는 조금 다르게 쓰고 있습니다.

```
피부에 하나
옷에 하나
```

**섞지 않습니다.** 자리를 나눕니다.

조말론 콜로뉴 3종으로 **세 가지 조합**을 써봤고, 그 과정에서 기준이 하나 생겼습니다. 왜 이게 겹쳐 뿌리기와 다른지, 그리고 어느 쪽에 뭘 둬야 하는지 적겠습니다.

## 피부와 옷은 발향이 전혀 다릅니다

이게 이 방식의 전부입니다.

| | 피부 | 옷 |
| --- | --- | --- |
| **열** | 체온이 있음 | 없음 |
| **휘발** | 빠름 | 느림 |
| **전개** | 탑 → 미들 → 베이스로 **변함** | 거의 **변하지 않음** |
| **지속** | 몇 시간 | **며칠 가기도 함** |
| **개인차** | 피부에 따라 향이 바뀜 | 거의 없음 |

피부에서는 체온이 향료를 밀어 올려서 **시간에 따라 성격이 바뀝니다.** 반면 섬유는 열이 없어서 **뿌린 그 인상이 그대로 오래 붙어 있습니다.**

전개 구조는 [탑·미들·베이스 노트 완전정리](/blog/perfume-notes/)에, 피부에 따라 향이 달라지는 이유는 [피부에 따라 향이 달라지는 이유](/blog/skin-chemistry/)에 정리해 뒀습니다.

**그래서 두 자리에 다른 향수를 두면, 둘이 화학적으로 섞이지 않고 각자 역할을 합니다.**

```
가까이서 · 시간이 지나며   피부 쪽 향  (변하는 향)
움직일 때 · 하루 종일      옷 쪽 향    (고정된 향)
```

---

## 어느 쪽에 뭘 둘지 — 기준은 하나입니다

처음엔 "무난한 걸 옷에, 변화 있는 걸 피부에" 두는 거라고 생각했습니다. **쓰다 보니 아니었습니다.**

실제로 제가 쓰는 기준은 훨씬 단순합니다.

> **그날 오래 맡고 싶은 향을 옷에 둡니다.**

위 표를 다시 보면 당연한 결론입니다. **옷은 변하지 않고 며칠까지 갑니다.** 오래 느끼고 싶은 향이 있다면 거기 두는 게 맞습니다.

```
옷     오늘의 주인공    오래 가니까
피부   나머지 하나      몇 시간이면 옅어지니까
```

**즉 옷이 받쳐주는 쪽이 아니라 앞에 나서는 쪽입니다.** 순서가 거꾸로였습니다.

### 그래서 잉글리시 페어가 옷에 자주 갑니다

제가 옷에 가장 자주 뿌리는 건 **잉글리시 페어 앤 프리지아**입니다. 다만 이유는 "무난해서 깔아주기 좋아서"가 아닙니다.

**호불호가 없고 깔끔해서**입니다. 하루 종일 따라다니는 향이라 **누구와 있어도 부담이 없어야 하는데**, 셋 중 그 조건을 가장 잘 맞춥니다. 그래서 **특별히 정하지 않은 날의 기본값**이 됩니다.

→ [잉글리시 페어 앤 프리지아 리뷰](/blog/jo-malone-english-pear-freesia/)

### 특정 향을 오래 맡고 싶은 날은 바꿉니다

반대로 **오늘은 이 향으로 하루를 보내고 싶다**는 날이 있습니다. 그럴 때 블랙베리 앤 베이나 우드 세이지 앤 씨 솔트를 옷에 올립니다.

```
기분을 띄우고 싶은 날    블랙베리 앤 베이를 옷에
잘 보이고 싶은 날        우드 세이지 앤 씨 솔트를 옷에
딱히 정하지 않은 날      잉글리시 페어를 옷에
```

**옷에 무엇을 두느냐가 그날의 인상을 정합니다.** 피부 쪽은 그 위에 몇 시간 얹히는 변주에 가깝습니다.

→ [우드 세이지 앤 씨 솔트 리뷰](/blog/jo-malone-wood-sage-sea-salt/)

### 다만 — 농도가 낮아야 합니다

놓치기 쉬운 조건이 하나 있습니다. **조말론 콜로뉴는 농도가 낮습니다.** 그래서 두 개를 써도 총량이 과해지지 않습니다.

진한 EDT나 EDP로는 권하지 않습니다. 제가 가진 존 바바토스 EDT 두 병으로는 이 방식을 안 씁니다 — **하나만으로도 충분히 세거든요.**

→ [향수 부향률 완전정리](/blog/perfume-concentration/)

## 겹쳐 뿌리는 레이어링과 뭐가 다른가

| | 겹쳐 뿌리기 | **나눠 뿌리기** |
| --- | --- | --- |
| 결과 | 섞여서 **제3의 향**이 됨 | 둘이 **각자 남음** |
| 실패 시 | 씻어내야 함 | **옷만 갈아입으면 됨** |
| 예측 | 어려움 | 쉬움 |
| 재미 | 큼 | 작음 |

**겹쳐 뿌리기는 새로운 향을 만드는 일**이고, **나눠 뿌리기는 두 향을 동시에 쓰는 일**입니다. 목적이 다릅니다.

제가 나눠 뿌리는 쪽을 쓰는 이유는 **되돌리기 쉬워서**입니다. 조합이 별로면 겉옷만 벗으면 되고, 피부 쪽은 원래 쓰던 그대로니까요. **실패 비용이 거의 없습니다.**

## 주의할 것

### ① 옷 소재를 먼저 보세요

**가장 중요합니다.** 향수의 알코올과 색소는 섬유에 얼룩을 남깁니다.

```
❌ 실크 · 가죽 · 모피 · 밝은 색 옷
⭕ 면 · 울 · 니트 · 어두운 색 겉옷
```

**잘 보이지 않는 안쪽에 먼저 시험해 보세요.** 겉옷 안감이나 옷깃 뒤가 무난합니다.

### ② 양은 평소의 절반씩

두 개를 쓰니까 **각각 줄여야 합니다.** 평소에 한 향수를 2회 뿌렸다면, 피부 1회 · 옷 1회가 기준입니다.

**20cm 정도 떨어뜨려 뿌리세요.** 가까우면 한 곳에 뭉쳐서 얼룩이 생깁니다. → [향수 뿌리는 위치와 올바른 방법](/blog/how-to-apply-perfume/)

### ③ 옷 향은 며칠 남습니다

**이게 이 방식의 유일한 단점**입니다.

섬유에 붙은 향은 오래갑니다. 같은 겉옷을 다음 날 또 입고 **다른 향수**를 뿌리면, 의도하지 않은 조합이 됩니다.

```
해결  겉옷을 몇 벌 돌려 입기
      또는 옷 쪽 향수를 하나로 고정하기
```

저는 뒤쪽입니다. **옷은 늘 잉글리시 페어**로 두면 변수가 사라집니다.

### ④ 밀폐된 공간에서는 하나만

사무실, 엘리베이터, 식당처럼 공간이 좁으면 **피부 쪽 하나로 충분합니다.** 두 겹은 밖에서 움직이는 날에 맞습니다. → [사무실에서 쓸 향수 고르기](/blog/office-fragrance/)

## 해본 조합 세 가지

지금까지 써본 조합입니다.

| 옷 | 피부 | 결과 |
| --- | --- | --- |
| 잉글리시 페어 | 우드 세이지 | 가장 자주 쓰는 조합 |
| 잉글리시 페어 | 블랙베리 앤 베이 | 좋았습니다 |
| **블랙베리 앤 베이** | **우드 세이지** | 좋았습니다 |

**셋 다 괜찮았습니다.** 실패한 조합이 없어서 솔직히 좀 싱거운 결과인데, 이유를 생각해 보면 납득이 갑니다.

### 왜 실패가 없었나

**셋 다 조말론 콜로뉴이기 때문**입니다.

```
농도가 낮음      →  둘을 써도 총량이 안 과함
성격이 또렷함    →  섞여도 서로를 뭉개지 않음
자리가 분리됨    →  애초에 화학적으로 섞이지 않음
```

특히 세 번째 조합이 흥미로웠습니다. **달달한 블랙베리를 옷에 깔고, 짠기 있는 우드 세이지를 피부에 올린** 건데, 글로 적으면 안 어울릴 것 같습니다. 그런데 **자리가 다르니 충돌하지 않습니다.** 겹쳐 뿌렸다면 결과가 달랐을 겁니다.

**이게 나눠 뿌리기의 장점입니다.** 겹쳐 뿌리기는 조합을 잘못 고르면 못 쓰게 되는데, 나눠 뿌리면 어지간해서는 사고가 안 납니다.

### 다만 — 같은 농도끼리여야 합니다

실패가 없었던 건 **셋이 같은 체급**이라서이기도 합니다. 제가 가진 존 바바토스 EDT 두 병을 섞었다면 결과가 달랐을 겁니다.

조말론 3종의 성격 차이는 [조말론 3종 비교](/blog/jo-malone-comparison/)에 정리해 뒀습니다.

## 처음 해본다면

```
① 오늘 오래 맡고 싶은 향을 정한다   →  그걸 옷에
② 소재를 확인한다                 안쪽에 먼저 시험
③ 각각 1회씩만                    총량이 늘어나는 걸 잊기 쉽습니다
④ 하루를 보내고 판단한다           옷 향은 저녁에 더 잘 느껴집니다
```

**④가 중요합니다.** 피부 향은 몇 시간이면 옅어지는데, 옷 향은 그때부터 드러납니다. **저녁에 어떤 인상이 남는지**가 이 방식의 진짜 결과입니다.

## 정리

**레이어링이라고 해서 꼭 겹쳐 뿌릴 필요는 없습니다.**

```
옷     변하지 않고 오래 가는 자리  →  그날 오래 맡고 싶은 향
피부   체온으로 변하는 자리       →  나머지 하나
```

기준은 하나입니다. **오늘의 주인공을 옷에 두세요.** 둘은 섞이지 않고 각자 남고, **실패해도 옷만 갈아입으면 되니 되돌리기도 쉽습니다.**

조말론 콜로뉴 3종으로 세 조합을 해봤는데 **전부 괜찮았습니다.** 자리가 분리돼 있어서 어지간해서는 사고가 안 납니다.

다만 **농도가 낮은 향수에서만** 권합니다. 콜로뉴 둘이면 적당한데, 진한 EDT나 EDP 둘이면 과합니다. 그리고 **옷 소재는 반드시 먼저 확인하세요.** 실크에 뿌리면 향수보다 비싼 걸 잃습니다.
