향수를 사다 보면 두 가지 질문에서 막힙니다.

```
몇 병을 가지고 있어야 하나
몇 ml짜리를 사야 하나
```

**둘은 사실 같은 질문입니다.** 향수는 상하는 물건이라, 병 수가 늘면 한 병당 쓰는 속도가 느려지고, 그러면 다 쓰기 전에 변질되기 때문입니다.

계산부터 해보겠습니다.

## 한 병을 다 쓰는 데 얼마나 걸리나

**1회 분사량은 보통 0.1ml 안팎**입니다. 하루 2회 뿌린다고 하면 0.2ml입니다.

| 용량 | 매일 쓸 때 | **3일에 한 번** |
| --- | --- | --- |
| 30ml | 약 5개월 | 약 1년 3개월 |
| 50ml | 약 8개월 | **약 2년** |
| 100ml | 약 1년 4개월 | **약 4년** |
| 125ml | 약 1년 8개월 | **약 5년** |

여기서 중요한 숫자가 하나 있습니다.

> **향수는 개봉 후 1\~3년이면 변질되기 시작합니다.**

표와 겹쳐 보면 문제가 보입니다. **100ml 이상을 매일 쓰지 않으면 다 쓰기 전에 변질됩니다.** 보관 조건에 따라 달라지긴 하지만, 방향은 분명합니다. → [향수 보관법과 유통기한](/blog/perfume-storage/)

## 그래서 몇 병이 적당한가

병 수와 용량은 함께 정해야 합니다.

| 보유 병 수 | 권장 용량 | 한 병당 사용 빈도 |
| --- | --- | --- |
| **1병** | 50\~100ml | 거의 매일 |
| **2\~3병** | **30\~50ml** | 2\~3일에 한 번 |
| 4\~6병 | 30ml 이하·소분 | 주 1\~2회 |
| 7병 이상 | 소분 위주 | 거의 안 쓰는 병이 생김 |

**결론부터 말하면 2\~3병이 가장 현실적입니다.**

```
1병   계절·상황을 못 가림. 질릴 수 있음
2~3병  계절과 상황을 나눌 수 있고, 다 쓸 수 있는 양
4병~   대부분 다 쓰기 전에 변질됨
```

## 2\~3병이면 어떻게 나누나

**계열이 아니라 역할로 나누는 게 실용적입니다.**

| 역할 | 성격 |
| --- | --- |
| **데일리** | 무난하고 존재감이 약한 것. 가장 자주 씀 |
| **따뜻한 계절 / 추운 계절** | 가벼운 쪽과 묵직한 쪽 하나씩 |
| (3병째) **자리용** | 존재감이 있는 것. 가끔 꺼냄 |

**데일리 한 병이 가장 중요합니다.** 실제로 쓰는 날이 압도적으로 많으니까요. 여기에 돈을 쓰는 게 효율이 좋습니다.

첫 3병을 고르는 순서는 [향수 입문 로드맵](/blog/beginner-roadmap/)에 따로 적어 뒀습니다.

## 용량 — 크다고 이득이 아닙니다

1ml당 단가만 보면 큰 쪽이 확실히 쌉니다.

```
50ml  12만원  →  1ml당 2,400원
100ml 18만원  →  1ml당 1,800원
```

**숫자만 보면 100ml가 이득입니다.** 그런데 다 못 쓰면 이 계산은 무의미합니다. 절반을 버리면 1ml당 3,600원을 낸 셈입니다.

### 실제로 겪어보니

저는 **125ml짜리를 두 병** 가지고 있습니다. 존 바바토스 아티산과 아티산 퓨어입니다.

**솔직히 과한 양입니다.** 둘 다 125ml인데 번갈아 쓰니 한 병당 소비 속도가 절반입니다. 계산해보면 다 쓰는 데 몇 년이 걸립니다. 조말론 쪽도 함께 쓰니 더 느려집니다.

```
병이 많을수록  →  한 병당 소비 속도가 느려짐  →  변질 위험 증가
```

**대용량의 함정이 여기 있습니다.** 한 병만 쓸 때의 계산으로 샀는데, 병이 늘면 전제가 깨집니다. → [아티산 vs 아티산 퓨어 비교](/blog/artisan-vs-pure/)

### 용량별로 정리하면

| 용량 | 이럴 때 |
| --- | --- |
| **5\~10ml (소분)** | 취향 확인용. **실패 비용이 가장 쌉니다** |
| **30ml** | 여러 병을 돌려 쓸 때. 가장 안전한 선택 |
| **50ml** | 데일리로 거의 매일 쓸 때 |
| 100ml 이상 | **한 병만 쓸 때.** 그 외엔 권하지 않습니다 |

**처음이라면 30\~50ml입니다.** 100ml는 "싸 보여서" 사게 되는데, 취향이 안 잡힌 상태에서 사면 가장 크게 손해 보는 선택입니다.

## 병이 늘어나는 걸 막는 방법

향수는 생각보다 쉽게 늘어납니다. 몇 가지 기준을 정해두면 도움이 됩니다.

**① 새로 사기 전에 가진 걸 다시 꺼내보세요**

계절이 바뀌면 같은 향수가 다르게 느껴집니다. 여름에 과했던 향수가 가을에 딱 맞는 경우가 흔합니다. → [가을 향수 고르는 기준](/blog/autumn-fragrance/)

**② 소분으로 먼저 확인하세요**

가장 효과적입니다. 3\~5ml를 몇천원에 써보고 결정하면, **안 쓰는 정품이 생기지 않습니다.** → [디캔트(소분) 완전정리](/blog/decant-guide/)

**③ 역할이 겹치면 사지 마세요**

이미 가진 향수와 **같은 자리에 쓸 향수**는 둘 중 하나가 방치됩니다. "비슷한데 조금 다른" 향수가 가장 위험합니다.

**④ 비우는 걸 목표로 삼으세요**

한 병을 끝까지 쓰면 그 향수를 제대로 안 겁니다. 계절마다 다르게 느껴지는 것도, 질리는 지점도 그때 알게 됩니다.

## 안 쓰는 향수는 어떻게 하나

이미 쌓였다면 이렇게 하면 됩니다.

| 상태 | 처리 |
| --- | --- |
| 아직 좋아함, 양이 많음 | **집·사무실·차에 나눠두기** — 쓰는 빈도가 올라갑니다 |
| 향은 괜찮은데 안 손이 감 | 옷장·서랍 방향제로 |
| 색이 진해지고 향이 시큼함 | **변질입니다.** 피부에 쓰지 마세요 |

변질 판단 기준은 [향수 보관법과 유통기한](/blog/perfume-storage/)에 정리해 뒀습니다.

## 정리

```
병 수    2~3병이 가장 현실적
용량     여러 병을 쓴다면 30~50ml
대용량   한 병만 쓸 때만 이득
소분     취향 확인의 가장 싼 방법
```

**향수는 모으는 물건이 아니라 쓰는 물건입니다.** 다 못 쓰고 변질되면 1ml당 단가가 아무리 싸도 손해입니다.

저는 125ml 두 병을 가지고 나서 이걸 체감했습니다. **다음에 산다면 50ml를 고를 겁니다.** 병이 여러 개면 소비 속도가 나눠진다는 걸 사기 전엔 계산에 안 넣었거든요.

**지금 몇 병을 가지고 있는지, 각각 얼마나 자주 쓰는지부터 세어보세요.** 그 숫자가 다음에 살 용량을 정해줍니다.
