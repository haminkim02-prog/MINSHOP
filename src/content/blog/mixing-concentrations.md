향수가 두 병 이상 생기면 **생각 못 한 문제가 하나 생깁니다.**

병마다 **뿌려야 하는 양이 다릅니다.** 그런데 손은 그걸 기억하지 못합니다.

저는 농도가 꽤 다른 두 브랜드를 같이 쓰고 있어서 이 문제를 자주 겪습니다. 그 얘기를 적습니다.

## 제가 쓰는 두 체급

```
조말론 콜로뉴 3종     낮은 농도
존 바바토스 EDT 2종   한 단계 위
```

둘 다 **"가벼운 농도"로 분류됩니다.** 콜로뉴와 EDT는 EDP나 퍼퓸보다 아래에 있으니까요.

**그런데 체감은 한 단계 차이납니다.**

| | 조말론 콜로뉴 | 존 바바토스 EDT |
| --- | --- | --- |
| 지속력 | 약 6시간 | **더 김** |
| 확산력 | 약함 | **셈** |
| 실내 1회 | 부족하지 않음 | **충분함** |
| 과하게 뿌렸을 때 | 사고 안 남 | **사고 남** |

농도 체계는 [향수 부향률 완전정리](/blog/perfume-concentration/)에 정리해 뒀습니다.

---

## 실제로 생기는 문제

### ① 조말론을 쓰다 존 바바토스를 뿌리면 과합니다

**가장 흔한 실수**입니다.

조말론은 2\~3회를 뿌려도 사고가 안 납니다. 그 감각이 손에 익은 상태에서 존 바바토스를 **같은 횟수로 뿌리면 과합니다.**

```
조말론 감각으로 존 바바토스 3회  →  밀폐된 공간에서 민폐
```

특히 **첫 향이 진한 향수라 더 티가 납니다.** 저는 그 구간에 스스로도 머리가 아플 정도인데, 양까지 많으면 더합니다. → [존 바바토스 아티산 리뷰](/blog/john-varvatos-artisan/)

### ② 반대로는 "향수를 안 뿌린 것 같습니다"

이쪽은 덜 위험하지만 더 자주 겪습니다.

존 바바토스를 며칠 쓰다가 조말론으로 돌아오면 **뿌렸는데 안 뿌린 것 같습니다.** 그래서 **덧뿌리게 됩니다.**

**여기에 함정이 하나 더 있습니다.** 자기 향은 20\~30분이면 코가 익숙해져서 안 느껴집니다. 체급 차이에 후각 순응까지 겹치면 **실제보다 훨씬 약하다고 착각합니다.**

```
체급이 낮아서 약함  +  코가 적응해서 못 느낌
→ "하나도 안 남았네" → 덧뿌림 → 주변에는 과하게 전달
```

**본인은 못 느끼는데 주변에는 그대로 갑니다.** → [향수 지속력을 늘리는 방법 7가지](/blog/perfume-longevity/)

### ③ 레이어링 기준도 달라집니다

저는 **피부와 옷에 다른 향수를 나눠 뿌리는 방식**을 자주 씁니다. 그런데 이건 **조말론 3종끼리만** 합니다.

이유는 단순합니다. **콜로뉴 농도라 두 개를 써도 총량이 과해지지 않기 때문**입니다. 존 바바토스 두 병으로 같은 걸 하면 **하나만으로도 충분히 센데 두 겹이 됩니다.**

→ [조말론 레이어링 — 섞지 않고 피부와 옷에 나눠 뿌리는 법](/blog/split-layering/)

## 왜 표기를 믿으면 안 되나

**부향률 표기는 법적 기준이 아닙니다.** 브랜드가 정합니다.

```
EDT 라고 적혀 있어도  →  브랜드마다 실제 농도가 다름
콜로뉴 는 EDT 보다    →  또 한 단계 아래
```

같은 `EDT` 표기인데 제가 가진 두 브랜드의 체감이 한 단계 차이나는 이유입니다. **숫자가 아니라 직접 재본 감각이 기준이 되어야 합니다.** → [향수 이름 읽는 법](/blog/perfume-labels/)

## 기준을 잡는 법

제가 쓰는 방법입니다. 복잡하지 않습니다.

### ① 병마다 "기본 횟수"를 정해두세요

머리로 기억하려 하면 매번 틀립니다. **병마다 숫자를 하나씩 붙여두는 게 낫습니다.**

| | 실내 | 야외 |
| --- | --- | --- |
| 조말론 콜로뉴 | 2회 | 3회 |
| 존 바바토스 EDT | **1회** | 2회 |

**절대적인 숫자가 아니라 본인 기준**입니다. 중요한 건 **"이 병은 저 병보다 한 번 적게"**라는 관계를 정해두는 것입니다.

### ② 바꿔 쓴 다음 날을 조심하세요

**체급을 바꾼 직후가 가장 위험합니다.** 전날 감각이 손에 남아 있거든요.

```
어제 조말론 → 오늘 존 바바토스   →  한 번 줄이기
어제 존 바바토스 → 오늘 조말론   →  덧뿌리지 않기
```

### ③ 확인은 팔 길이로

양이 적당한지 판단하는 기준입니다. **팔을 뻗은 거리 안에서만 느껴지면 적정**입니다. 그보다 멀리 가면 과합니다.

본인 코로는 판단이 안 되니, **밖에 나갔다 들어와서** 다시 맡아보는 게 그나마 정확합니다. → [향수 뿌리는 위치와 올바른 방법](/blog/how-to-apply-perfume/)

## 처음 두 번째 병을 살 때

**가능하면 비슷한 농도로 고르는 게 편합니다.**

```
콜로뉴를 쓰고 있다  →  두 번째도 콜로뉴나 가벼운 EDT
EDP 를 쓰고 있다    →  두 번째도 비슷한 급
```

체급이 섞이면 **매번 기준을 다시 잡아야 합니다.** 익숙해지면 괜찮지만, 처음 두세 병 단계에서는 불필요한 변수입니다.

다만 **계절이나 상황을 나눌 생각이라면 섞는 게 맞습니다.** 저도 그래서 섞어 쓰고 있고요 — 실내가 많은 날은 조말론, 하루가 긴 날은 존 바바토스 식으로요.

## 정리

**농도가 다른 향수를 같이 쓰면 양 조절 감각이 매번 어긋납니다.**

```
낮은 농도 → 높은 농도   과하게 뿌리게 됨   ← 위험
높은 농도 → 낮은 농도   덧뿌리게 됨        ← 본인만 모름
```

해결은 단순합니다. **병마다 기본 횟수를 정해두고, 바꿔 쓴 다음 날을 조심하는 것.**

그리고 **표기를 믿지 마세요.** 같은 `EDT`라도 브랜드마다 체급이 다릅니다. 제 경우 조말론 콜로뉴와 존 바바토스 EDT가 둘 다 "가벼운 농도"로 분류되는데, 실제로는 한 단계 차이났습니다.
