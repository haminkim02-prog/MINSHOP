리뷰를 읽다 보면 **"두세 번 뿌리면 적당합니다"**라는 문장이 자주 나옵니다. 제 글에도 썼습니다.

그런데 **이 말은 병이 같을 때만 통합니다.**

네 병을 같이 쓰면서 알게 된 건, **같은 "두 번"이 병마다 다른 양**이라는 겁니다. 어떤 병은 두 번이 적당하고, 어떤 병은 두 번이 과합니다.

---

## 분사구는 통일된 규격이 아닙니다

**향수 펌프는 브랜드·용량마다 다릅니다.** 한 번 눌렀을 때 나오는 양이 보통 **0.05\~0.15ml 사이**에서 설계되는데, 그 안에서도 **세 배 가까이 차이**가 납니다.

바뀌는 요소는 세 가지입니다.

```
① 1회 분사량     한 번에 얼마나 나오나
② 입자 크기      안개처럼 퍼지나, 물줄기처럼 쏘나
③ 분사 각도      넓게 퍼지나, 한 점에 모이나
```

**①만 같아도 ②③이 다르면 피부에 닿는 양이 달라집니다.** 넓게 퍼지는 쪽은 상당량이 공중에서 날아가고, 모아서 쏘는 쪽은 거의 다 피부에 닿습니다.

---

## 제 네 병은 이렇게 달랐습니다

**정밀 측정은 아닙니다.** 같은 거리에서 같은 횟수로 뿌리고, 손등에 닿는 느낌과 번지는 범위를 비교한 수준입니다. 그래도 **차이는 바로 알 수 있었습니다.**

| 병 | 퍼짐 | 체감 |
| --- | --- | --- |
| 조말론 100ml | 넓게 안개처럼 | 두 번이 적당 |
| 조말론 30ml | 좁고 또렷하게 | **두 번이면 많습니다** |
| 존 바바토스 125ml | 중간, 양이 넉넉 | 두 번이 적당 |

**같은 조말론인데 30ml와 100ml가 다릅니다.** 작은 병은 펌프도 작아서, 넓게 퍼지지 않고 **한 자리에 모여 떨어집니다.**

그래서 **30ml 우드 세이지를 100ml 쓰던 감각으로 두 번 뿌리면** 한 자리에 진하게 뭉칩니다. 전체 양은 비슷해도 **농도 분포가 다릅니다.**

### 존 바바토스는 잔량이 안 보입니다

**분사량과는 별개로 불편한 지점**이 하나 있었습니다.

존 바바토스 아티산은 **병을 라탄으로 감싸놓은 디자인**입니다. 보기엔 좋은데, **안이 안 보입니다.**

```
조말론    →  유리가 투명해서 남은 양이 보입니다
바바토스  →  라탄에 가려서 흔들어봐야 압니다
```

**얼마나 남았는지 모르는 상태로 쓰게 됩니다.** 다 쓴 걸 뿌리고 나서야 비었다는 걸 알게 되는 경우가 생깁니다. 이건 [휴대 관련 글](/blog/carrying-perfume/)에도 적었지만, **출근 직전에 알면 곤란합니다.**

## 내 병의 적정 횟수를 정하는 법

**남의 숫자를 그대로 쓰지 말고 한 번 맞춰두면 오래 갑니다.**

### 1단계 — 휴지에 뿌려보세요

**흰 휴지를 펴고 평소 거리에서 한 번** 뿌립니다.

```
젖은 자국이 동전만 함     →  분사량이 적은 병
손바닥만 하게 번짐        →  분사량이 많은 병
한 점에 진하게 고임       →  모아 쏘는 병. 거리를 더 두세요
```

**병을 바꿀 때마다 10초면 확인됩니다.** 이것만 해도 첫날 과하게 뿌리는 일은 없습니다.

### 2단계 — 적게 시작해서 올리세요

**새 병은 한 번으로 시작하세요.**

하루 써보고 **아무도 반응이 없고 본인도 옷에서 안 느껴지면** 다음 날 한 번 더 올립니다. 반대 순서로 하면 **이미 과한 상태로 하루를 보내게 되고, 본인은 모릅니다.**

자기 향을 못 맡는 이유는 [따로 정리해뒀습니다](/blog/cant-smell-own-perfume/).

### 3단계 — 거리로 조절하세요

**횟수는 정수라 조절이 거칠습니다.** 한 번과 두 번 사이가 없습니다.

그럴 때는 **거리를 씁니다.**

| 원하는 효과 | 거리 |
| --- | --- |
| 진하게, 좁게 | 10\~15cm |
| 보통 | **20cm** |
| 옅게, 넓게 | 30cm 이상 |

**"한 번은 적고 두 번은 많다"**는 상황은 **한 번을 가까이, 또는 두 번을 멀리**로 해결됩니다.

## 분사구가 고장 났을 때

**싼 병일수록 펌프가 먼저 망가집니다.** 제 경험은 아니지만 흔한 문제라 적어둡니다.

```
안 나온다        →  노즐 막힘. 미지근한 물에 노즐만 담가보세요
찔끔 나온다      →  스프링 약화. 교체 외엔 답이 없습니다
새어나온다       →  펌프 결합부. 눌러서 다시 끼워보세요
```

**노즐이 막히는 건 향수가 말라붙어서입니다.** 오래 안 쓴 병을 다시 쓸 때 자주 생깁니다. **한 달에 한 번은 뿌려주는 게 예방**입니다.

---

## 정리

```
① 1회 분사량은 병마다 세 배까지 다릅니다
② 같은 브랜드도 용량이 다르면 퍼짐이 다릅니다
③ 새 병은 휴지에 한 번 뿌려서 확인하세요
④ 횟수가 거칠면 거리로 조절하세요
```

**"두 번"이라는 숫자는 그 사람의 병 기준입니다.** 제 글의 숫자도 마찬가지입니다.

그래서 **리뷰의 분사 횟수는 참고만 하고, 내 병은 직접 맞추는 게 맞습니다.** 휴지 한 장이면 끝나는 일이고, **한 번 해두면 그 병을 다 쓸 때까지 안 틀립니다.**
