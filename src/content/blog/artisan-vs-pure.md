향수를 고르다 보면 이런 상황을 자주 만납니다. **원작이 있고, 이름 뒤에 단어 하나가 더 붙은 버전이 또 있습니다.**

```
Artisan
Artisan Pure
```

둘 다 살 필요가 있을까요. 아니면 하나만 사도 될까요. **둘 다 쓰면서 확인한 답**을 적습니다.

## 플랭커가 뭔가

원작이 성공하면 브랜드가 내놓는 파생 제품을 **플랭커(flanker)**라고 부릅니다.

흔한 오해가 **"플랭커는 원작을 진하게 만든 버전"**이라는 것인데, 대부분 사실이 아닙니다. **조합 자체를 다시 짠 별개의 향수**인 경우가 많습니다.

이 두 제품이 딱 그 사례입니다. → [향수 이름 읽는 법](/blog/perfume-labels/)

## 기본 정보

| | 아티산 | 아티산 퓨어 |
| --- | --- | --- |
| 출시 | 2009 | 2017 |
| 조향사 | 로드리고 플로레스루 | **로드리고 플로레스루** (동일) |
| 계열 | 시트러스 아로마틱 | 시트러스 |
| 부향률 | EDT | EDT |
| 용량 | 125ml | 125ml |

**같은 조향사가 8년 뒤에 다시 만들었습니다.** 그래서 "같은 사람이 같은 주제를 다시 풀면 어떻게 달라지는가"를 볼 수 있는 흔치 않은 사례입니다.

## 노트 구성 비교

| 단계 | 아티산 | 아티산 퓨어 |
| --- | --- | --- |
| 탑 | 클레멘타인, 탠저린, 마조람, 타임 | 클레멘타인, **레몬, 만다린, 베르가못**, 타임, 마조람 |
| 미들 | 오렌지블라썸, 진저, **라벤더, 자스민** | **쁘띠그레인**, 진저 |
| 베이스 | 머스크, 우디, 앰버 | 우디, 머스크, 앰버, **오리스 루트** |

구성만 보면 방향이 분명합니다.

```
퓨어는  시트러스를 늘리고  →  꽃을 덜어냈습니다
```

원작의 라벤더·자스민·오렌지블라썸이 빠지고, 시트러스가 2종에서 4종으로 늘었습니다. 이름의 `Pure`는 **"더 진하다"가 아니라 "더 단순하고 깨끗하다"**는 뜻으로 읽힙니다.

**그런데 노트표와 실제 체감은 다를 수 있습니다.** 아래는 직접 써본 기록입니다.

## 직접 비교

<!-- 개별 리뷰에서 측정한 값을 옮겨오세요 -->

| 항목 | 아티산 | 아티산 퓨어 |
| --- | --- | --- |
| **첫인상** | 시트러스 + 허브 | **시트러스가 더 강함** |
| **잔향** | **우디 느낌** | 깔끔하게 옅어짐 |
| **성격** | 복잡하고 무게가 있음 | 단순하고 깨끗함 |
| 지속력 | 조말론보다 김 | 조말론보다 김 |
| 확산력 | 조말론보다 셈 | 조말론보다 셈 |

### 실제로 얼마나 다른가

**노트표가 가리키는 방향이 실제 체감과 일치했습니다.** 이게 생각보다 드문 일입니다.

퓨어는 **시트러스가 확실히 더 강합니다.** 시트러스가 2종에서 4종으로 늘어난 게 그대로 느껴집니다. 반대로 원작은 **잔향에서 나무 느낌이 올라옵니다.** 베이스 구성은 비슷한데, 원작 쪽이 미들의 라벤더·자스민을 거쳐 내려오면서 더 두껍게 느껴집니다.

**정리하면 이렇습니다.**

```
아티산       시트러스로 시작해 → 우디로 끝남
아티산 퓨어   시트러스로 시작해 → 시트러스로 끝남
```

**"같은 향수의 다른 버전"보다는 "방향이 다른 두 향수"에 가깝습니다.** 뼈대는 공유하는데 끝나는 지점이 다릅니다.

### 지속력과 확산력은

**둘 다 비슷합니다.** 그리고 둘 다 **조말론 콜로뉴(약 6시간)보다 확실히 길고 셉니다.**

같은 `EDT` 표기라도 브랜드에 따라 체감이 이렇게 다릅니다. 부향률 표기를 절대적으로 믿으면 안 되는 이유입니다. → [향수 부향률 완전정리](/blog/perfume-concentration/)

## 둘 다 살 필요가 있나

**취향이 뚜렷하다면 하나면 충분합니다.**

끝나는 지점이 다르니, **어느 쪽 마무리를 좋아하는지**로 갈립니다.

```
우디 잔향이 좋다      →  아티산
깔끔한 시트러스가 좋다  →  아티산 퓨어
```

둘 다 가질 가치는 **계절이나 상황을 나눠 쓸 때** 생깁니다. 여름엔 퓨어, 나머지 계절엔 원작 식으로요. 다만 **125ml짜리 두 병은 다 쓰기 어려운 양**이라, 처음이라면 하나로 시작하는 걸 권합니다.

## 하나만 고른다면 — 아티산

**원작 쪽입니다.**

퓨어가 더 상큼하긴 한데, **상큼함은 첫 향에서 끝납니다.** 반면 원작은 시간이 지나면서 우디로 성격이 바뀌어서 **하루 안에 두 가지 인상**을 줍니다. 오래 쓸 한 병이라면 변화가 있는 쪽이 덜 질립니다.

그리고 솔직히 — **둘 다 첫 향은 제 취향이 아니었습니다.** 그렇다면 잔향이 더 마음에 드는 쪽을 고르는 게 맞습니다.

> 다만 **여름에 시원한 향수 한 병이 필요하다면 퓨어**입니다. 그 용도로는 원작보다 낫습니다.

## 상황별로 나누면

| 상황 | 추천 | 이유 |
| --- | --- | --- |
| **여름** | 퓨어 | 시트러스가 강해 더 시원합니다 |
| **가을·겨울** | 아티산 | 우디 잔향이 계절과 맞습니다 |
| 사무실 | 둘 다 **1회만** | 조말론 감각으로 뿌리면 과합니다 |
| 하루가 긴 날 | 둘 다 | 지속력이 받쳐줍니다 |
| 첫 향이 중요한 자리 | **둘 다 비추천** | 탑 노트가 두 향수의 약점입니다 |

## 이 사례가 말해주는 것

플랭커를 고를 때 적용할 수 있는 교훈입니다.

**① 수식어를 믿지 마세요**

`Pure`는 "순수한"이지만 실제로는 "시트러스를 늘리고 꽃을 뺐다"는 뜻이었습니다. `Intense`, `Elixir`, `Absolu`도 마찬가지로 브랜드마다 의미가 다릅니다.

**② 노트표를 비교하면 방향이 보입니다**

무엇이 추가되고 무엇이 빠졌는지를 보면, 적어도 **어느 쪽으로 틀었는지**는 짐작할 수 있습니다.

**③ 그래도 결국 맡아봐야 합니다**

노트표가 같은 방향을 가리켜도 체감은 다를 수 있습니다. **원작이 좋았다고 플랭커도 좋으리라 기대하지 마세요.** 따로 시향해야 합니다.

**④ 소분으로 확인하는 게 가장 쌉니다**

둘 다 125ml입니다. 한쪽이 안 맞으면 손실이 큽니다. → [디캔트 완전정리](/blog/decant-guide/)

## 정리

**플랭커는 원작의 "더 진한 버전"이 아니었습니다.** 같은 조향사가 만들었는데도 끝나는 지점이 다릅니다. 원작은 우디로, 퓨어는 시트러스로 마무리됩니다.

**`Pure`는 "더 진하다"가 아니라 "더 단순하고 깨끗하다"**는 뜻이었습니다. 이름에 붙은 단어의 의미는 브랜드마다 다르니, 글자만 보고 추측하지 마세요.

**하나만 산다면 원작**을 권합니다. 하루 안에 변화가 있어서 덜 질립니다. 다만 **여름 전용 한 병**이 필요하다면 퓨어가 낫습니다.

그리고 두 향수 모두 **첫 향으로 판단하면 손해입니다.** 매장에서 30초 맡고 결정했다면 둘 다 안 샀을 겁니다. 시향은 최소 30분\~1시간 뒤에 판단하세요. → [향수 시향 제대로 하는 법](/blog/how-to-test-fragrance/)
