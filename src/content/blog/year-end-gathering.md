**12월이 가까워지면 모임이 몰립니다.** 송년회, 회식, 동창회.

그리고 이 자리들은 **향수 입장에서 조건이 꽤 나쁩니다.**

```
좁은 방  +  난방  +  사람 많음  +  술  +  음식 냄새
```

**평소 양 그대로 뿌리고 가면 과해지는 조합**입니다. 하나씩 보면 왜 그런지 분명합니다.

---

## 네 가지가 동시에 향을 키웁니다

### ① 난방 — 발향이 빨라집니다

**향은 온도로 올라옵니다.** 겨울이라 적게 날 거라 생각하고 더 뿌리는데, **실내는 밖과 전혀 다른 환경**입니다.

```
밖  (영하)    →  향이 거의 안 퍼집니다
실내 (25도)   →  여름보다 더 세게 납니다
```

**추워서 두 번 더 뿌린 양이, 난방 들어온 방에서 그대로 터집니다.** 겨울 모임에서 가장 흔한 실수입니다.

### ② 밀폐 — 빠져나갈 곳이 없습니다

**겨울에는 창문을 안 엽니다.** 향이 공간에 쌓입니다.

야외나 환기가 되는 곳이라면 같은 양도 퍼져서 흩어지는데, **닫힌 방에서는 농도가 유지됩니다.**

### ③ 거리 — 평소보다 가깝습니다

**모임 자리는 사람 간격이 좁습니다.** 긴 테이블에 붙어 앉거나 좌식이면 더 그렇습니다.

```
평소 대화 거리    →  1m 안팎
회식 자리         →  50cm 이하
```

**향수는 거리에 민감합니다.** 사무실에서 적당했던 양이 여기서는 다릅니다.

### ④ 술 — 체온이 올라갑니다

**술을 마시면 혈관이 확장되고 피부 온도가 올라갑니다.** 향이 더 많이, 더 빨리 올라옵니다.

**게다가 본인 코는 더 둔해집니다.** 모임이 길어질수록 **실제 발향은 세지고 자각은 약해지는 방향**으로 벌어집니다.

---

## 그래서 — 평소의 절반

**가장 단순하고 확실한 조정입니다.**

| 평소 | 모임 날 |
| --- | --- |
| 2회 | **1회** |
| 1회 | **1회, 거리를 멀게** |
| 목·귀 뒤 | **허리·옷 안쪽** |

**위치를 아래로 내리는 게 핵심**입니다. 목이나 귀 뒤는 **앉아 있을 때 상대 코 높이**입니다. 허리나 셔츠 안쪽으로 내리면 같은 양도 체감이 줄어듭니다.

**뿌리는 시점도 당기세요.** 출발 직전이 아니라 **집에서 나오기 30분 전**이면, 도착할 때쯤 초반 강한 구간이 지나가 있습니다.

## 어떤 향이 그 자리에 맞나

**계열에 따라 밀폐 공간에서의 성격이 다릅니다.**

### 괜찮은 쪽

```
시트러스·아쿠아틱   가볍고 금방 옅어집니다
가벼운 우디         음식 냄새와 덜 싸웁니다
비누·머스크         무난하고 거부감이 적습니다
```

### 위험한 쪽

```
진한 플로럴         좁은 공간에서 빨리 무거워집니다
구르망(바닐라·캐러멜) 음식 냄새와 섞입니다
스파이시·오리엔탈   난방과 만나면 과해집니다
```

**구르망 계열이 의외로 문제**입니다. 달콤한 향은 **음식 냄새와 같은 영역**이라 서로 간섭합니다. 디저트 가게 안에서 바닐라 향수를 뿌린 상태를 생각하면 됩니다.

음식 냄새와 향수가 섞이는 문제는 [따로 정리한 글](/blog/smell-over-smell/)이 있습니다.

## 제 다섯 병이라면

**가진 것 중에서 고른다면 이렇습니다.**

| 향수 | 모임 자리 평가 |
| --- | --- |
| **조말론 우드 세이지 앤 씨 솔트** | **1순위.** 가볍고 짠 느낌이라 무거워지지 않습니다 |
| 조말론 잉글리시 페어 앤 프리지아 | 괜찮지만 **플로럴이라 양 조절이 더 필요**합니다 |
| 존 바바토스 아티산 | 괜찮습니다. 지속력이 길어 **한 번이면 충분** |
| 존 바바토스 아티산 퓨어 | 원작보다 가벼워 **밀폐 공간에 더 맞습니다** |

**조말론 콜로뉴 농도가 이런 자리에서는 장점**이 됩니다. 평소엔 짧아서 아쉬운데, **빨리 옅어지는 게 여기선 안전 장치**입니다.

반대로 **존 바바토스 쪽은 오래 가는 만큼 한 번만** 뿌려야 합니다. 두 번 뿌리면 모임이 끝날 때까지 그대로입니다.

## 아예 안 뿌리는 선택도 있습니다

**경우에 따라 그게 정답입니다.**

```
횟집·고깃집 회식        →  안 뿌리는 게 낫습니다
노래방으로 이어지는 자리 →  더 좁고 더 덥습니다
어르신 많은 자리        →  향에 민감한 분이 있을 수 있습니다
차로 이동하는 모임      →  차 안이 가장 좁습니다
```

**"향수를 뿌리면 예의"라는 건 상황에 따라 다릅니다.** 좁고 더운 자리에서는 **안 뿌린 쪽이 배려**인 경우가 많습니다.

대신 **깨끗한 상태로 가는 것**이 더 중요합니다. 샤워하고 깨끗한 옷을 입는 쪽이 어떤 향수보다 낫습니다.

---

## 정리

```
① 난방·밀폐·거리·술이 동시에 향을 키웁니다
② 평소의 절반, 위치는 허리 아래로
③ 나가기 30분 전에 뿌리세요
④ 구르망·진한 플로럴은 피하세요
⑤ 자리에 따라 안 뿌리는 게 정답입니다
```

**겨울 모임에서 향수가 문제가 되는 건 양을 많이 뿌려서가 아니라, 환경이 양을 키워서**입니다. 같은 두 번이 여름 야외와 겨울 실내에서 완전히 다른 결과가 됩니다.

**한 번만 뿌리고 30분 일찍.** 이 두 가지면 대부분 해결됩니다.
