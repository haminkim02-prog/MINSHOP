향수가 한 병일 때는 고민이 없습니다. 그걸 뿌리면 됩니다.

**여러 병이 되면 아침마다 고르게 됩니다.** 그리고 고르는 데 기준이 없으면 **결국 손에 익은 하나만 쓰게 됩니다.**

두 달 동안 다섯 병을 돌려 쓰면서 **선택 패턴이 생겼습니다.** 어떤 날 뭘 집는지 적어둡니다. 상황별 일반론은 [TPO별 향수 고르기](/blog/tpo-fragrance/)에 따로 정리해 뒀고, 이 글은 **실제 기록**입니다.

## 다섯 병의 역할

두 달이 지나니 **병마다 자리가 생겼습니다.**

| 향수 | 역할 |
| --- | --- |
| **잉글리시 페어 앤 프리지아** | **기본값.** 정하지 않은 날 |
| 블랙베리 앤 베이 | 기분을 띄우고 싶은 날 (다 썼습니다) |
| 우드 세이지 앤 씨 솔트 | 잘 보이고 싶은 날 |
| 존 바바토스 아티산 | 하루가 긴 날 · 가을·겨울 |
| 아티산 퓨어 | 깔끔하게 가고 싶은 날 |

**처음부터 이렇게 나눈 게 아닙니다.** 쓰다 보니 손이 가는 자리가 갈렸고, 나중에 보니 규칙이 보였습니다.

## 실제로 어떻게 고르나

### 정하지 않은 날 — 잉글리시 페어

**가장 자주 집는 병**입니다. 특별한 일정이 없거나, 고민하기 싫은 아침에요.

이유는 하나입니다. **호불호가 없어서 아무 데나 가도 됩니다.** 누구를 만나든 부담이 없고, 양을 좀 더 뿌려도 사고가 안 납니다.

```
100ml 를 산 것도 이 향수
옷에 뿌리는 것도 이 향수
```

**기본값이 하나 있으면 나머지 선택이 편해집니다.** "오늘은 뭔가 다르게"라는 생각이 들 때만 다른 병으로 가면 되니까요. → [잉글리시 페어 앤 프리지아 리뷰](/blog/jo-malone-english-pear-freesia/)

### 기분이 가라앉은 날 — 블랙베리 앤 베이

**가장 단 향수**입니다. 뿌리면 캔디가게에 들어선 것 같아서 **기분이 같이 올라갑니다.**

50ml를 끝까지 썼는데 **질리지 않았습니다.** 매일 뿌리는 향수가 아니었기 때문입니다. 꺼낼 때마다 반가웠습니다.

**달아서 질리는 게 아니라 매일 뿌려서 질립니다.** 역할을 좁게 잡은 게 결과적으로 맞았습니다. → [블랙베리 앤 베이 리뷰](/blog/jo-malone-blackberry-bay/)

### 잘 보이고 싶은 날 — 우드 세이지

**가장 어른스럽게 느껴지는 향수**입니다. 중요한 자리나 괜찮은 인상을 주고 싶은 날에 꺼냅니다.

30ml를 샀는데 **그 선택이 맞았습니다.** 역할이 좁으니 소비가 느립니다. 100ml였다면 몇 년이 걸렸을 겁니다.

그리고 **가을이 되고 나서 비중이 늘었습니다.** 다섯 병 중 이 계절에 가장 잘 맞아서요. → [우드 세이지 앤 씨 솔트 리뷰](/blog/jo-malone-wood-sage-sea-salt/)

### 하루가 긴 날 — 존 바바토스 아티산

**아침에 나가서 늦게 들어오는 날**입니다. 조말론 콜로뉴는 약 6시간인데, 이쪽은 더 갑니다.

다만 **뿌리고 바로 누군가를 만나는 날에는 피합니다.** 첫 향이 진해서 가장 안 좋은 구간을 보여주게 되거든요.

```
하루가 길다 + 아침에 약속이 없다  →  아티산
```

**가을·겨울에 비중이 올라갑니다.** 잔향의 나무 느낌이 계절과 맞아서요. → [존 바바토스 아티산 리뷰](/blog/john-varvatos-artisan/)

### 깔끔하게 가고 싶은 날 — 아티산 퓨어

원작보다 **시트러스가 강하고 단순합니다.** 계절을 안 가려서 아무 때나 쓸 수 있고요.

존재감은 원하는데 **복잡한 인상은 피하고 싶을 때** 집습니다. → [아티산 vs 아티산 퓨어](/blog/artisan-vs-pure/)

## 고를 때 실제로 보는 것

적고 보니 **제품 이름이 아니라 세 가지 조건**으로 고르고 있었습니다.

```
① 오늘 얼마나 오래 나가 있나      →  지속력
② 아침에 누구를 만나나            →  첫 향이 중요한지
③ 기분을 바꾸고 싶은가            →  단 향인지 아닌지
```

**계열이나 노트는 거의 안 봅니다.** 두 달 전에는 그게 기준일 거라고 생각했는데 아니었습니다.

### 실내에 오래 있는 날은 농도를 봅니다

하나 더 생긴 기준입니다. **난방이 들어온 실내에 오래 있는 날에는 조말론 쪽으로 갑니다.**

존 바바토스는 실내에서 한 번 줄여야 하는데, 그걸 매번 신경 쓰느니 **애초에 농도가 낮은 걸 뿌리는 게 편합니다.** → [농도가 다른 향수를 번갈아 쓰면 생기는 일](/blog/mixing-concentrations/)

## 안 쓰게 되는 병이 생기지 않으려면

**역할이 겹치면 한 쪽이 방치됩니다.**

제 다섯 병은 역할이 다 다릅니다. 그래서 **전부 손이 갑니다.** 만약 잉글리시 페어와 비슷한 향수를 하나 더 샀다면, 둘 중 하나는 서랍에 들어갔을 겁니다.

```
새 향수를 살 때 질문
→ "지금 가진 것 중 이 자리를 대신할 게 있나?"
```

**있으면 사지 마세요.** 비슷한데 조금 다른 향수가 가장 위험합니다. → [향수 몇 병이 적당한가](/blog/how-many-perfumes/)

## 정리

두 달을 쓰고 나니 **병마다 자리가 생겼습니다.**

```
기본값 하나        정하지 않은 날에 집는 것
기분용 하나        역할을 좁게
인상용 하나        중요한 자리
지속력용 하나      하루가 긴 날
```

**기본값이 있는 게 가장 중요합니다.** 그게 있으면 나머지는 "특별한 날"만 담당하면 되니까 역할이 선명해집니다.

그리고 **고를 때 보는 건 향이 아니라 상황**이었습니다. 지속력, 아침 일정, 기분 — 이 세 가지면 다섯 병 중 하나가 정해집니다.

향수를 늘릴 때도 **"이 자리가 비어 있나"**를 먼저 보시면, 안 쓰는 병이 생기지 않습니다.
