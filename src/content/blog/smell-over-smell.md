고깃집에서 나온 뒤, 담배를 피운 뒤, 땀이 난 뒤 — **향수를 뿌려서 덮으려는 경우**가 있습니다.

**대개 역효과입니다.** 가려지는 게 아니라 섞입니다.

왜 그런지, 그리고 어떻게 해야 하는지 정리했습니다.

## 향수는 냄새를 덮지 못합니다

**가장 먼저 짚어야 할 부분**입니다.

향수는 **탈취제가 아닙니다.** 냄새 분자를 없애거나 중화하는 게 아니라, **자기 향을 추가**할 뿐입니다.

```
냄새 + 향수  =  가려짐  ❌
냄새 + 향수  =  둘 다 남음  ⭕
```

그리고 **둘이 섞이면 대개 각각보다 나쁩니다.** 고기 냄새 위의 플로럴, 담배 냄새 위의 시트러스는 어느 쪽도 좋게 느껴지지 않습니다.

### 왜 더 나빠지나

**코는 "낯선 조합"에 민감합니다.**

익숙한 냄새 하나는 금방 배경이 되는데, **서로 안 어울리는 두 냄새가 겹치면** 계속 인식됩니다. 그래서 **덮으려고 뿌린 향수가 오히려 주목을 끕니다.**

게다가 **본인은 못 느낍니다.** 자기 향은 20\~30분이면 코가 적응하고, 그 사이에 있던 공간의 냄새에도 적응합니다. **주변 사람만 둘 다 맡고 있는 상황**이 됩니다.

---

## 냄새가 어디에 붙어 있나

**피부보다 옷과 머리카락이 문제입니다.**

| 부위 | 냄새가 붙는 정도 |
| --- | --- |
| **옷 (특히 모·니트)** | **가장 심함.** 섬유가 붙잡습니다 |
| **머리카락** | 심함. 표면적이 넓습니다 |
| 피부 | 비교적 덜함. 씻으면 대부분 빠집니다 |

**고깃집에서 나와 옷에서 냄새가 나는 건 피부 문제가 아닙니다.** 그래서 손목에 향수를 뿌려봐야 소용이 없습니다. **냄새의 출처와 향수의 출처가 다른 자리**니까요.

```
냄새는 옷에서  →  향수는 손목에서
→  두 냄새가 따로 올라옵니다
```

## 순서를 바꾸세요 — 빼고 나서 뿌리기

**향수는 마지막입니다.** 냄새를 먼저 줄이고 나서 뿌려야 합니다.

### ① 옷 — 환기가 가장 빠릅니다

```
바람이 통하는 곳에 걸어두기    가장 효과적
옷에 밴 냄새는 대개 몇 시간이면 상당히 빠집니다
```

급하다면 **화장실에서 옷을 털고 바람을 쐬는 것만으로도** 꽤 줄어듭니다. 섬유 탈취제가 있으면 더 좋고요.

**다만 탈취제와 향수를 같이 쓰면** 또 다른 조합이 생깁니다. **무향 탈취제**를 쓰시는 게 낫습니다.

### ② 머리카락 — 향수를 뿌리지 마세요

머리에서 냄새가 난다고 **머리카락에 향수를 뿌리는 건 좋지 않습니다.**

```
❌ 알코올이 모발을 건조하게 만듭니다
❌ 두피에 닿으면 자극이 됩니다
❌ 냄새와 섞여 더 복잡해집니다
```

**빗질과 환기가 낫습니다.** 머리카락용 제품을 쓰려면 **헤어 미스트**처럼 그 용도로 나온 것을 쓰세요.

→ [향수와 피부 안전](/blog/perfume-skin-safety/)

### ③ 피부 — 씻는 게 가장 빠릅니다

손과 얼굴만 씻어도 체감이 달라집니다. **씻고 나서 뿌리는 순서**를 지키세요.

### ④ 그다음에 향수

냄새가 줄어든 뒤에 **평소보다 적게** 뿌리세요. 이미 공간에 냄새가 남아 있을 수 있으니, 평소 양으로 가면 전체 농도가 과해집니다.

```
옷 환기  →  손 씻기  →  향수 1회
```

## 상황별로

### 고깃집·식당에서 나왔을 때

**다음 일정이 있다면 겉옷을 벗어두고 들어가는 게 최선**입니다. 냄새는 주로 겉옷에 붙습니다.

겉옷을 식당 밖이나 차에 두고 들어가면 **그 옷만 보존**됩니다. 이게 향수보다 효과가 큽니다.

### 담배 냄새

**가장 안 가려집니다.** 담배 냄새는 입자가 작고 끈적해서 섬유에 깊이 붙습니다.

**향수로 덮으려는 시도는 거의 실패합니다.** 환기와 세탁 외에 방법이 많지 않고, **손을 씻는 것**이 즉시 효과가 있는 몇 안 되는 방법입니다.

### 땀

**땀 자체는 거의 무취입니다.** 냄새는 피부 세균이 땀을 분해하면서 생깁니다.

그래서 **향수를 뿌린다고 해결되지 않습니다.** 오히려 향료가 체취와 섞이면 예상 못 한 냄새가 납니다.

**데오드란트가 맞는 해결책**이고, 향수는 그다음입니다. 그리고 **겨드랑이에 향수를 뿌리지 마세요** — 자극이 되고 체취와 섞입니다.

### 운동 후

**씻기 전에는 뿌리지 마세요.** 땀이 남은 상태에서 뿌리면 향이 변하고, 땀이 더 나면서 같이 퍼집니다.

## 반대로 — 향수가 냄새의 원인이 될 때

**밀폐된 공간에서는 향수가 민폐가 됩니다.**

```
엘리베이터 · 대중교통 · 회의실 · 식당
```

**본인은 후각 순응으로 못 느낍니다.** 특히 농도가 높은 향수를 쓰거나 덧뿌린 경우 그렇습니다.

기준은 **팔 길이**입니다. 팔을 뻗은 거리 안에서만 느껴지면 적정이고, 그보다 멀리 가면 과합니다.

## 정리

```
향수는 탈취제가 아닙니다    덮이지 않고 섞입니다
냄새는 옷과 머리에 붙습니다  피부에 뿌려도 출처가 다릅니다
순서는 "빼고 나서 뿌리기"    환기 → 씻기 → 향수
```

**가장 효과적인 건 겉옷을 벗어두고 들어가는 것**입니다. 향수로 해결하려는 시도보다 훨씬 확실합니다.

그리고 **냄새가 걱정되는 날에는 향수를 평소보다 적게** 쓰세요. 두 냄새가 겹치면 어느 쪽도 좋게 느껴지지 않고, **본인만 그걸 모르는 상태**가 됩니다.
