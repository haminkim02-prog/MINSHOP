향수를 좋아하는데 **사무실에서는 못 쓰겠다**는 분이 많습니다. 눈치가 보여서입니다.

그 걱정은 합리적입니다. 사무실은 **향수를 쓰기에 가장 불리한 조건**을 전부 갖춘 공간이거든요.

## 왜 사무실이 가장 어려운가

```
① 밀폐돼 있다        향이 빠져나가지 못하고 누적됩니다
② 8시간을 함께 있다   잠깐 스치는 게 아닙니다
③ 거리가 가깝다      옆자리는 1~2미터입니다
④ 선택권이 없다      동료는 자리를 피할 수 없습니다
⑤ 냉난방이 돈다      기온이 높아 향이 더 퍼집니다
```

**⑤를 특히 놓치기 쉽습니다.** 겨울에 난방이 세게 돌면 실내 기온이 25도를 넘는데, 이러면 향이 여름처럼 퍼집니다. 밖에서 딱 좋게 뿌리고 들어왔다가 과해지는 경우가 여기서 나옵니다.

---

# 고르는 조건 4가지

## 1. 농도 — EDT 이하

```
✅  Cologne, Eau de Toilette
⚠️  Eau de Parfum  (분사량을 줄이면 가능)
❌  Parfum, Extrait, Intense, Elixir
```

사무실용으로 EDP 이상을 사면 **매일 양 조절에 신경 써야 합니다.** 처음부터 가벼운 농도를 고르는 게 편합니다. → [향수 부향률 완전정리](/blog/perfume-concentration/)

## 2. 계열 — 깨끗한 쪽

| 적합 | 이유 |
| --- | --- |
| **아쿠아틱** | "거의 무향에 가까운 깨끗함". 호불호가 가장 적습니다 |
| **푸제르** | 비누 향. 단정한 인상 |
| **시트러스** | 상쾌하고, 과해도 덜 불쾌합니다 |
| **가벼운 우디** | 차분하고 신뢰감 있는 인상 |

| 부적합 | 이유 |
| --- | --- |
| 앰버·구르망 | **달고 무겁습니다.** 밀폐 공간에서 가장 부담이 큽니다 |
| 진한 플로럴 | 존재감이 강해 인지가 빠릅니다 |
| 중동 계열 | 확산력이 과합니다 |

**핵심은 "달지 않을 것"입니다.** 단 향은 확산력이 약해도 금방 인지됩니다. 반대로 깨끗한 계열은 비슷한 강도여도 "향수 뿌렸네"라는 인상을 덜 줍니다.

→ [향 계열 8가지 정리](/blog/fragrance-families/)

## 3. 확산력 — 지속력보다 중요합니다

사무실에서 문제가 되는 건 **오래 남는 것이 아니라 멀리 퍼지는 것**입니다.

```
❌ 피해야 할 것   확산력 강함 (지속력은 상관없음)
✅ 이상적인 것    오래 남지만 가까이서만 느껴짐  ← 스킨 센트
```

리뷰에서 **"스킨 센트"**, **"가까이서만"**, **"확산력 약함"** 같은 표현을 찾으세요. 반대로 **"향수 뭐 쓰냐고 물어봐요"**는 사무실용으로는 경고 신호입니다.

→ [은은한 향수 고르는 법](/blog/subtle-fragrance-guide/)

## 4. 가격 — 부담 없는 선에서

매일 쓰는 용도라 **소모 속도가 빠릅니다.** 첫 사무실용 향수로 20만원 넘는 걸 살 이유가 없습니다. 5\~12만원대면 충분합니다.

---

## 얼마나 뿌려야 하나

여기가 제품 선택보다 중요합니다. **대부분의 사무실 향수 사고는 제품이 아니라 양에서 납니다.**

```
실내 기준   1~2회
겨울 난방   1회
여름 냉방   1~2회 (밖 기온 기준으로)
```

### 기준은 "팔 길이"입니다

**내 팔을 뻗은 거리 안에서만 느껴지면 적정**입니다. 옆자리 동료가 "향수 뿌렸네"를 인지하면 이미 조금 과합니다.

### 위치로 강도를 조절하세요

같은 향수라도 어디에 뿌리는지에 따라 체감이 완전히 달라집니다.

| 위치 | 사무실 적합도 |
| --- | --- |
| 목·쇄골 | ✕ 얼굴에 가까워 가장 강하게 퍼집니다 |
| 손목·팔 안쪽 | ○ 무난합니다 |
| **무릎 뒤·발목** | **◎ 아래에서 위로 천천히 올라와 가장 은근합니다** |
| **옷 안쪽** | ◎ 피부 접촉도 피할 수 있습니다 |

**무릎 뒤나 발목**은 잘 알려지지 않았는데 사무실에 가장 적합합니다. 가까이 왔을 때만 느껴지거든요.

→ [향수 뿌리는 위치와 올바른 방법](/blog/how-to-apply-perfume/)

### 출근 30분 전에 뿌리세요

뿌린 직후가 가장 강합니다. **집에서 나서기 30분 전**에 뿌리면 사무실 도착 즈음엔 탑 노트가 가라앉아 있습니다.

---

## 가장 흔한 실수 — 덧뿌리기

점심 먹고 와서 "향이 다 날아갔네" 하고 다시 뿌리는 것. **이게 사무실 향수 민폐의 1순위 경로입니다.**

뿌린 지 20\~30분이면 후각이 적응해서 자기 향은 안 느껴집니다. **사라진 게 아니라 내 코가 무뎌진 겁니다.** 주변에는 그대로 남아 있습니다.

```
덧뿌리기 규칙:  최소 4시간 경과 + 1회만
확인 방법:      밖에 나갔다 들어와서 맡아보기
```

---

## 실제로 어떤 구조가 맞나

제품을 나열하지는 않겠습니다. 맡아보지 않은 걸 추천하는 건 이 블로그 원칙과 맞지 않습니다.

대신 제가 쓰면서 "사무실에 적합하다"고 느낀 구조를 공유합니다. **조말론 콜로뉴 3종**인데, 세 가지 모두 이랬습니다.

```
총 지속력   약 6시간      ← 하루를 버티기에 충분
확산력      중반부터 크게 줄어듦
후반        가까이 왔을 때만 느껴지는 잔향
```

**"오래 남지만 강하게 퍼지는 건 초반뿐"** — 사무실용으로 이상적인 형태입니다. 과하게 뿌려도 폭력적으로 퍼지지 않고, 시간이 지나면 알아서 은은해집니다.

세 가지 중에서는 **잉글리시 페어 앤 프리지아**가 가장 무난했습니다. 튀는 구석이 없어서 어떤 자리에서도 어색하지 않았습니다. 반대로 **블랙베리 앤 베이는 달아서** 사무실에서는 한 번 줄이는 게 좋았습니다.

기록은 [조말론 콜로뉴 3종 비교](/blog/jo-malone-comparison/)에 있습니다.

**중요한 건 브랜드가 아니라 이 구조입니다.** 어느 브랜드든 "EDT 이하 + 달지 않은 계열 + 낮은 확산력"이면 비슷하게 동작합니다.

---

## 회사 분위기를 먼저 읽으세요

조건을 아무리 잘 맞춰도, **애초에 향수를 안 쓰는 분위기인 곳**이 있습니다.

**먼저 확인할 것**
- 동료들이 향수를 쓰는가
- 향에 민감하다고 말한 사람이 있는가
- 자리 간격이 얼마나 되는가
- 환기가 되는 사무실인가

**이런 상황이면 아예 쓰지 않는 게 맞습니다.**
- 바로 옆에 임산부나 호흡기 질환이 있는 동료가 있을 때
- 창문이 없고 환기가 전혀 안 되는 공간
- 음식·향 관련 업무 (조리, 품질관리 등)

## 향수 대신 쓸 수 있는 것

사무실에서 향수 자체가 부담이라면 더 약한 형태가 있습니다.

| 대안 | 특징 |
| --- | --- |
| **헤어 미스트** | 훨씬 약하고 확산이 적습니다 |
| **바디 미스트** | 1\~2시간, 가볍습니다 |
| **솔리드 퍼퓸** | 알코올이 없고 확산이 거의 없습니다 |
| **섬유 향수** | 겉옷 안쪽에만 |

**솔리드 퍼퓸**이 특히 사무실에 잘 맞습니다. 본인만 느끼는 수준으로 쓸 수 있습니다.

## 정리

- 사무실은 **밀폐 + 장시간 + 근거리**라 가장 까다로운 환경입니다
- **EDT 이하 + 달지 않은 계열 + 낮은 확산력**이 기본 조건입니다
- 지속력이 아니라 **확산력**을 보세요
- **팔 길이 안에서만** 느껴지면 적정입니다. 실내 1\~2회
- **무릎 뒤·발목·옷 안쪽**에 뿌리면 강도가 크게 줄어듭니다
- 출근 **30분 전**에 뿌려서 탑 노트를 가라앉히세요
- **점심 후 덧뿌리기가 민폐 1순위**입니다. 안 느껴지는 건 사라져서가 아닙니다
- 회사 분위기와 주변 사람을 먼저 보세요

사무실에서 향수를 쓰는 목표는 **"좋은 향을 알리는 것"이 아니라 "거슬리지 않는 것"**입니다. 이 기준으로 고르면 실패하지 않습니다.
