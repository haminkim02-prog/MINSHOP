"은은한 향수 추천"을 검색해 보면 이상한 일이 벌어집니다. **결과에 나오는 향수들이 은은하지 않습니다.**

지속력 10시간, 확산력 강함으로 알려진 제품이 "은은하다"는 이름으로 추천되곤 합니다. 쓰는 사람마다 "은은하다"의 기준이 다르기 때문입니다.

그래서 이 글은 제품 목록이 아니라 **조건**을 정리합니다.

---

## "은은하다"를 정의해야 합니다

향수의 성능은 두 가지로 나뉩니다. **이 둘을 섞어 쓰니까 혼란이 생깁니다.**

| | 뜻 | 은은한 향수는 |
| --- | --- | --- |
| **지속력** | 얼마나 **오래** 남는가 | 길어도 됨 |
| **확산력** | 얼마나 **멀리** 퍼지는가 | **낮아야 함** |

```
은은한 향수 = 확산력이 낮은 향수
            ≠ 빨리 사라지는 향수
```

**이 구분이 이 글의 전부입니다.** 오래 남으면서 가까이서만 느껴지는 향수가 가장 이상적이고, 실제로 그런 제품이 있습니다.

이런 상태를 **스킨 센트(skin scent)**라고 부릅니다. 피부에 가까이 대야 맡아지는 향인데, **단점이 아니라 하나의 스타일**입니다. 용어는 [향수 용어 사전](/blog/perfume-glossary/)에 정리했습니다.

---

## 왜 은은한 향수를 찾는가

이유가 다 다르고, **이유에 따라 답이 달라집니다.**

| 이유 | 필요한 것 |
| --- | --- |
| 사무실에서 눈치 보임 | 낮은 확산력 |
| 향수 뿌리면 머리가 아픔 | 낮은 확산력 + 가벼운 계열 → [자세히](/blog/fragrance-headache/) |
| 주변에 민감한 사람이 있음 | 낮은 확산력 |
| 향수 티 내는 게 싫음 | 낮은 확산력 + 흔한 계열 |
| **첫 향수라 감이 없음** | **실수해도 회복 가능한 것** |

마지막이 의외로 중요합니다. 향수가 처음이면 **얼마나 뿌려야 적당한지 모릅니다.** 이때 강한 향수를 고르면 사고가 납니다. 은은한 향수는 **과하게 뿌려도 폭력적으로 퍼지지 않습니다.**

# 은은함을 결정하는 조건 4가지

## 1. 부향률 — 콜로뉴 또는 EDT

```
Eau Fraîche  1~3%     ← 가장 약함
Cologne      2~5%
EDT          5~15%    ← 여기까지가 안전
────────────────────
EDP          15~20%
Parfum       20~40%   ← 은은함과 거리가 멉니다
```

다만 **부향률에는 법적 기준이 없습니다.** 브랜드마다 다르니 절대적으로 믿지 마세요. → [향수 이름 읽는 법](/blog/perfume-labels/)

## 2. 계열 — 가볍고 달지 않은 쪽

| 은은하기 쉬운 계열 | 존재감이 강해지는 계열 |
| --- | --- |
| 시트러스 | 앰버 |
| 아쿠아틱 | 구르망 |
| 가벼운 푸제르 | 진한 플로럴 |
| 머스크 중심 | 스파이시 |

**단 향이 가장 눈에 띕니다.** 확산력이 약해도 "뿌렸구나"가 바로 인지됩니다. 은은함을 원하면 **달지 않은 쪽**을 고르세요.

→ [향 계열 8가지 정리](/blog/fragrance-families/)

## 3. 원료 — 머스크와 앰브렛

`머스크`, `앰브렛(ambrette)`, `이소 E 슈퍼` 같은 원료가 중심이면 **피부에 붙어 은근하게 남는** 성격이 강해집니다.

특히 머스크는 **사람에 따라 거의 안 느껴지기도 합니다.** 은은함을 원한다면 장점이고, 존재감을 원한다면 단점입니다.

→ [천연 향료와 합성 향료](/blog/natural-vs-synthetic/)

## 4. 리뷰에서 이 단어를 찾으세요

제품 설명보다 **사용 후기의 표현**이 정확합니다.

```
✅  "스킨 센트"   "가까이서만"   "은은하다"
    "확산력 약함"   "본인만 느껴짐"   "과하지 않다"

❌  "비스트 모드"   "방 전체"   "멀리서도"
    "확산력 강함"   "존재감 확실"   "뿌리고 다니면 물어봄"
```

**"향수 뭐 쓰냐고 물어봐요"는 은은하지 않다는 뜻입니다.** 칭찬처럼 보이지만 확산력이 강하다는 신호입니다.

## 실제로 써보고 확인한 예

제품을 길게 나열하지 않겠습니다. **맡아보지 않은 걸 추천하는 게 "은은한 향수 추천" 글들이 부정확해지는 이유**이기 때문입니다.

대신 제가 직접 쓰면서 기록한 예를 들겠습니다. **조말론 콜로뉴 3종**인데, 세 가지 모두 같은 구조였습니다.

```
총 지속력    약 6시간      ← 짧지 않습니다
확산력       중반부터 크게 줄어듦
후반         가까이 왔을 때만 느껴지는 잔향
```

**"오래 남지만 강하게 퍼지는 건 초반뿐"** — 이게 앞에서 말한 이상적인 형태입니다. 지속력은 확보하면서 확산력은 낮은 구조.

세 제품의 성격은 이렇게 갈렸습니다.

| | 성격 | 은은함 |
| --- | --- | --- |
| 잉글리시 페어 앤 프리지아 | 무난하고 포근함 | ★★★ 가장 무난 |
| 블랙베리 앤 베이 | 달달함 | ★★ 단 향이라 인지는 잘 됨 |
| 우드 세이지 앤 씨 솔트 | 건조하고 고급스러움 | ★★★ 달지 않아 부담 적음 |

기록은 [조말론 콜로뉴 3종 비교](/blog/jo-malone-comparison/)에 정리했습니다.

**다시 강조하면, 브랜드가 아니라 구조입니다.** "콜로뉴/EDT + 달지 않은 계열 + 낮은 확산력" 조건을 만족하면 어느 브랜드든 비슷한 결과가 나옵니다.

## 은은한 향수의 함정 — 반드시 읽으세요

여기서 대부분이 실수합니다.

> **은은한 향수일수록 과하게 뿌리게 됩니다.**

약하니까 안 느껴지고, 안 느껴지니까 더 뿌리고, 결국 은은한 향수를 강한 향수처럼 쓰게 됩니다. **은은한 향수를 고른 의미가 사라집니다.**

게다가 뿌린 지 20\~30분이면 후각이 적응해서 자기 향은 원래 안 느껴집니다. **"안 느껴진다 = 사라졌다"가 아닙니다.**

### 확인하는 법

```
① 뿌리고 밖에 나갔다가 다시 들어와서 맡기
② 옷깃을 다른 사람에게 맡아보게 하기
③ 덧뿌리기 전 최소 4시간 경과 확인
```

**주변 사람의 반응이 본인 코보다 정확합니다.** → [향수 지속력을 늘리는 방법](/blog/perfume-longevity/)

## 은은한 향수가 안 맞는 경우

솔직히 말하면 모두에게 맞는 건 아닙니다.

- **"향수 뿌린 티"를 내고 싶은 사람** — 은은한 향수는 아무도 눈치채지 못합니다
- **하루 종일 확실히 남기를 원하는 사람** — 덧뿌려야 합니다
- **가격 대비 존재감을 따지는 사람** — 같은 값에 훨씬 강한 향수가 많습니다

이런 경우라면 부향률이 높은 EDP나 중동 브랜드가 맞습니다. → [향수 브랜드 지형도](/blog/perfume-brands/)

## 고르는 순서

```
① 부향률 확인      Cologne / EDT 인가
② 계열 확인        달지 않은가 (시트러스·아쿠아틱·푸제르·머스크)
③ 리뷰 검색        "확산력" 관련 표현 확인
④ 소분 구매        3~5ml, 3천~1만원
⑤ 며칠 착용        주변 반응까지 확인
⑥ 정품 구매
```

④\~⑤를 건너뛰지 마세요. **은은한 향수는 특히 매장 시향으로 판단이 안 됩니다.** 매장에서는 탑 노트만 맡는데, 은은한 향수의 진가는 잔향에 있기 때문입니다. → [디캔트 완전정리](/blog/decant-guide/)

## 정리

- **은은함 = 확산력이 낮은 것.** 빨리 사라지는 것이 아닙니다
- **콜로뉴/EDT + 달지 않은 계열 + 머스크 계열 원료**가 기본 조합입니다
- 리뷰에서 **"스킨 센트", "가까이서만"**을 찾고, **"방 전체", "물어봄"**은 피하세요
- **"향수 뭐 쓰냐고 물어봐요"는 은은하지 않다는 뜻**입니다
- 가장 큰 함정은 **안 느껴져서 더 뿌리는 것**입니다. 주변 반응으로 확인하세요
- 매장 시향으로는 판단이 안 됩니다. **소분으로 며칠 써보세요**

향수는 존재감이 클수록 좋은 게 아닙니다. **상황에 맞는 강도**가 좋은 겁니다.
