향수를 쓰기 시작한 지 **석 달**이 됐습니다.

[두 달 차에 틀렸던 것 다섯 가지](/blog/two-months-wrong/)를 적었는데, 그 뒤로 한 달이 더 지났습니다. **그 사이에 바뀐 것**과 **아직 답이 안 난 것**을 나눠서 적어둡니다.

**11월 말 기준이고, 겨울은 이제 시작입니다.** 확정된 결론이 아니라 중간 기록입니다.

---

## 숫자부터

```
시작할 때   →  다섯 병
지금        →  네 병
```

**블랙베리 앤 베이 50ml를 다 썼습니다.** 석 달 만입니다.

남은 건 **잉글리시 페어 앤 프리지아 100ml, 우드 세이지 앤 씨 솔트 30ml, 존 바바토스 아티산 125ml, 아티산 퓨어 125ml.**

**한 병을 끝까지 쓴 게 이번이 처음**이었는데, 그 경험이 생각보다 많은 걸 바꿨습니다.

---

## 바뀐 것 ① — "다 쓴다"가 기준이 됐습니다

**사기 전에는 "좋은 향인가"만 봤습니다.** 지금은 **"다 쓸 수 있는 양인가"**를 같이 봅니다.

50ml를 석 달에 비웠다는 건, **100ml면 여섯 달, 125ml면 일곱 달 이상**이라는 뜻입니다. 그런데 저는 **125ml를 두 병** 가지고 있습니다.

```
125ml × 2병  →  번갈아 쓰면 1년 반이 넘습니다
```

**향수는 열어두면 품질이 떨어집니다.** 1년 반이면 후반부는 처음과 같은 향이 아닐 가능성이 큽니다. [보관과 유통기한 글](/blog/perfume-storage/)에 적은 그대로입니다.

**두 달 차에 "125ml 두 병은 과했다"고 썼는데, 그건 돈 이야기였습니다.** 지금은 **품질 이야기**로 바뀌었습니다. 같은 결론인데 이유가 달라졌습니다.

## 바뀐 것 ② — 병이 비는 과정을 보게 됐습니다

**블랙베리가 바닥을 보이기 시작하면서** 쓰는 방식이 달라졌습니다.

```
많이 남았을 때  →  아무 날에나 뿌립니다
얼마 안 남으면  →  "오늘 쓸 만한 날인가"를 따집니다
```

**아껴 쓰게 됩니다.** 그런데 이건 좋은 습관이 아니었습니다. 아끼는 동안 **그 향수를 안 쓰고 지나간 날이 늘었고**, 결국 마지막 10ml는 두 달 가까이 걸렸습니다.

**빨리 다 쓰고 다시 사는 쪽이** 향 상태로도, 만족도로도 낫습니다. 이건 [공병 처리 글](/blog/empty-bottle/)에도 적었습니다.

## 바뀐 것 ③ — 양을 줄였습니다

**이번 달에 가장 크게 바뀐 부분**입니다.

자기 향은 **20\~30분이면 안 느껴진다**는 걸 알고 나서, **"안 느껴진다"를 기준으로 덧뿌리던 습관**을 버렸습니다. [따로 쓴 글](/blog/cant-smell-own-perfume/)에 정리해뒀습니다.

그리고 **병마다 분사량이 다르다**는 것도 이번에 확인했습니다. 100ml를 쓰다가 30ml 우드 세이지로 넘어가면 **같은 두 번이 다른 양**입니다. 이건 [분사량 글](/blog/spray-amount/)에 썼습니다.

```
예전   →  감각으로 판단. 안 느껴지면 더 뿌림
지금   →  한 번 뿌리고 10분. 그래도 모자라면 추가
```

**규칙으로 바꾸고 나서 과하게 뿌린 날이 없어졌습니다.**

---

## 아직 답이 안 난 것

### ① 겨울 예측이 맞았는지

**11월 초에 겨울을 예측하는 글**을 썼습니다. 요지는 이랬습니다.

```
조말론 3종      →  겨울에도 괜찮을 것 같다
존 바바토스 2종 →  밖에서는 좋고 실내가 문제일 것 같다
가장 궁금한 것  →  우드 세이지가 겨울에도 1등일까
```

**아직 판단할 수 없습니다.** 11월 말은 **난방이 막 들어오기 시작한 시점**이고, 진짜 조건은 12월\~1월입니다.

**지금 "맞았다"고 쓰면 그건 예측을 확인한 게 아니라 예측을 반복하는 것**이라서, 비워둡니다. **1월에 답을 적겠습니다.**

### ② 다음 병을 뭘 살지

**블랙베리를 다시 살지 결정 못 했습니다.**

```
다시 산다   →  이미 아는 향. 실패가 없습니다
새로 산다   →  계열을 넓힐 기회입니다
```

**석 달 동안 쓴 다섯 병이 전부 시트러스·우디 쪽**이라, 계열이 좁습니다. 그런데 좁다는 걸 알면서도 **거기서 만족하고 있다면 굳이 넓혀야 하나**라는 생각도 듭니다.

**이건 결론이 나면 적겠습니다.**

### ③ 향수를 몇 병까지 둘지

**네 병도 많다는 생각이 듭니다.**

[몇 병이 적당한가](/blog/how-many-perfumes/)에 쓸 때는 일반론이었는데, 직접 겪어보니 **"다 쓸 수 있는 병 수"**가 현실적인 상한이었습니다. 저한테 그건 **두세 병**에 가깝습니다.

---

## 석 달 동안 안 바뀐 것

**의외로 이쪽이 중요한 것 같아서 적습니다.**

```
우드 세이지가 가장 자주 손이 갑니다   석 달째 그대로입니다
아티산 퓨어가 가장 무난합니다          실패하는 날이 없습니다
잉글리시 페어는 상황을 탑니다          좋은데 아무 날에나 꺼내진 않습니다
```

**첫 달에 "제일 좋다"고 느낀 게 석 달 뒤에도 그대로**라는 게 저한테는 가장 의미 있는 결과였습니다.

**향수는 오래 써봐야 안다**는 말을 많이 하는데, **적어도 순위는 생각보다 일찍 정해지는 것 같습니다.** 바뀌는 건 순위가 아니라 **왜 그런지에 대한 설명**이었습니다.

---

## 석 달 쓰고 권하는 것

**지금 시작하는 분이라면 이 순서를 권합니다.**

```
① 작은 병으로 시작하세요        30ml면 충분합니다
② 한 병을 끝까지 쓰세요          두 병을 반씩 쓰는 것보다 배웁니다
③ 양은 규칙으로 정하세요         감각으로 하면 늘 과해집니다
④ 기록하세요                     석 달 전 생각은 기억 안 납니다
```

**④가 이 글을 쓰는 이유**입니다. 두 달 차에 적어둔 게 없었다면, **제가 뭘 틀렸는지도 몰랐을 겁니다.**

---

## 정리

```
한 병을 비웠습니다              석 달, 50ml
기준이 바뀌었습니다             "좋은 향" → "다 쓸 수 있는 양"
양을 규칙으로 바꿨습니다        감각은 계속 틀립니다
겨울은 아직 모릅니다            1월에 적겠습니다
순위는 안 바뀌었습니다          우드 세이지가 그대로 1위
```

**다음 기록은 겨울이 지나고 나서**입니다. 그때는 **예측 글의 답**을 적을 수 있을 것 같습니다.
