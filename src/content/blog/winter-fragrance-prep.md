11월입니다. 곧 겨울이고, **향수가 또 달라질 시기**입니다.

가을에 한 번 겪었습니다. **제 예상이 빗나갔고**, 왜 빗나갔는지도 정리했습니다. 그 경험이 있으니 **겨울은 미리 예측해 두고 나중에 맞춰보려고 합니다.**

틀리면 틀린 대로 적겠습니다. 가을에도 그랬으니까요.

## 가을에 배운 것

먼저 지난 계절을 정리하고 가겠습니다.

**예상** — 조말론 콜로뉴 3종은 농도가 낮으니 가을에 묻힐 것이다.
**결과** — 세 병 다 잘 맞았고, 우드 세이지가 가장 잘 어울렸다.

왜 빗나갔는지 따져보니 이랬습니다.

```
기온이 낮으면  →  확산은 줄지만 휘발이 느려져 잔향이 길어짐
```

**저는 잔향 쪽 사람**이라 그 변화가 손해가 아니라 이득이었습니다. → [가을 향수 고르는 기준](/blog/autumn-fragrance/) · [향수 두 달 쓰면서 틀렸던 것 5가지](/blog/two-months-wrong/)

**교훈은 하나입니다.** 계열별 표나 계절별 추천은 **평균적인 이야기**고, 본인이 첫 향 쪽인지 잔향 쪽인지에 따라 반대로 작용할 수 있습니다.

## 겨울의 변수는 두 개입니다

가을보다 하나가 더 늘어납니다.

### ① 기온이 더 내려갑니다

가을에 일어난 변화가 **더 심해질 것**입니다.

```
확산    더 줄어듦
잔향    더 길어짐
```

**방향은 같고 정도가 세질 뿐**입니다. 그러니 가을에 괜찮았던 향수는 겨울에도 괜찮을 가능성이 높습니다.

### ② 난방이 들어옵니다 ← 이게 새 변수입니다

**겨울에만 생기는 조건**입니다. 가을에는 실내외 온도차가 크지 않았는데, 겨울엔 확 벌어집니다.

```
밖    영하. 향이 거의 안 퍼짐
안    난방으로 20도 이상. 향이 여름처럼 퍼짐
```

**같은 양을 뿌렸는데 장소에 따라 체감이 두 배씩 차이납니다.** 밖에서 적당하다고 느낀 양이 실내에서는 과해집니다.

여기에 **두꺼운 외투**가 더해집니다. 옷이 향을 가두고 있다가 **실내에서 외투를 벗는 순간 한꺼번에 퍼집니다.**

## 그래서 예측해보면

### 조말론 3종 — 겨울에도 괜찮을 것 같습니다

**가을에 잘 맞았으니 겨울도 비슷할 것**으로 봅니다. 그리고 **난방 실내에서는 오히려 유리합니다.**

농도가 낮아서 **실내에서 과해질 걱정이 없습니다.** 외투를 벗어도 사고가 안 날 겁니다.

```
예측   밖에서는 더 약하게 느껴짐
       실내에서는 딱 맞음
```

다만 **밖에 오래 있는 날에는 아쉬울 수 있습니다.** 그건 겪어봐야 알겠습니다.

### 존 바바토스 2종 — 밖에서는 좋고 실내가 문제일 것 같습니다

**아티산은 원래 가을·겨울용으로 생각하고 있던 병**입니다. 잔향의 나무 느낌이 계절과 맞고, 지속력도 깁니다.

문제는 실내입니다. 이미 **난방이 들어온 공간에서 한 번 줄여야 하는 향수**인데, 겨울엔 그 상황이 매일 옵니다.

```
예측   밖에서는 제일 잘 맞음
       실내에서는 1회로 줄여야 함
       외투 벗는 순간 주의
```

→ [농도가 다른 향수를 번갈아 쓰면 생기는 일](/blog/mixing-concentrations/)

### 가장 궁금한 건 우드 세이지입니다

**가을에 다섯 병 중 가장 잘 맞았던 병**입니다. 겨울에도 그럴지가 제일 궁금합니다.

```
겨울에도 1등일까   →  건조한 성질이 계절과 맞을 수 있음
아니면 밀릴까      →  너무 가벼워서 추위에 묻힐 수 있음
```

**가을에 틀렸던 터라 이번엔 단정하지 않겠습니다.** 리뷰에도 겨울 칸은 비워뒀습니다. → [우드 세이지 앤 씨 솔트 리뷰](/blog/jo-malone-wood-sage-sea-salt/)

## 겨울에 실제로 할 것

예측과 별개로, **지금 해둘 수 있는 건 정해져 있습니다.**

### ① 가진 향수부터 다시 꺼내보세요

**새로 사기 전에 이걸 먼저** 하시길 권합니다. 가을에 제가 그걸로 예상을 뒤집었거든요.

```
여름에 과했던 향수   →  겨울엔 맞을 수 있습니다
가을에 괜찮았던 향수  →  대개 겨울도 괜찮습니다
```

**돈이 안 드는 유일한 방법**이고, 가진 것 중에 겨울용이 이미 있을 가능성이 꽤 높습니다.

### ② 실내 기준으로 뿌리세요

**겨울에 가장 흔한 실수**입니다. 밖에서 약하게 느껴진다고 더 뿌리면, **난방 실내에 들어가는 순간 과해집니다.**

```
나가기 전에는 조금 부족한 듯이
실내에서 외투를 벗을 때를 기준으로
```

사무실 기준은 [사무실에서 쓸 향수 고르기](/blog/office-fragrance/)에 정리해 뒀습니다.

### ③ 외투에 뿌리는 걸 고려해보세요

겨울에 특히 쓸모 있습니다. **섬유는 향을 오래 붙잡는데, 겨울 외투는 며칠씩 갑니다.**

**피부에 하나, 외투 안쪽에 하나**를 두면 섞이지 않고 각자 남습니다. 저는 조말론 3종으로 이 방식을 자주 씁니다.

> ⚠️ **소재를 먼저 확인하세요.** 가죽·모피·밝은 색 코트에는 얼룩이 남습니다. 안감 안쪽에 먼저 시험하세요.

겨울에 한 병을 추가한다면 **우디나 앰버 계열**이 가장 안전합니다. 따뜻하고 묵직해서 추운 계절과 맞습니다.

다만 **앰버와 구르망은 존재감이 강해서** 양 조절 실패 시 사고가 납니다. 처음이라면 우디 쪽을 권합니다. → [향수 계열 8가지 정리](/blog/fragrance-families/)

## 정리

**겨울의 변수는 기온과 난방 두 개**입니다.

```
기온    가을의 변화가 더 심해짐. 방향은 같음
난방    실내외 체감이 두 배씩 차이남  ← 겨울에만 생기는 조건
```

**그래서 "밖에서 적당한 양"이 아니라 "실내에서 적당한 양"으로 뿌려야 합니다.** 외투를 벗는 순간이 기준입니다.

그리고 **새로 사기 전에 가진 걸 먼저 꺼내보세요.** 가을에 저는 그걸로 예상을 뒤집었습니다.

이 글에 적은 건 **전부 예측입니다.** 겨울을 지나고 나서 **맞았는지 틀렸는지 다시 적겠습니다.** 가을에 다섯 가지를 틀렸으니, 이번에도 몇 개는 틀릴 것 같습니다.
