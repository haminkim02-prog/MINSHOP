향수를 밖에서 다시 뿌리고 싶을 때가 있습니다. 하루가 길거나, 저녁에 약속이 있거나요.

그런데 **들고 다니는 게 생각보다 번거롭습니다.** 무겁고, 깨지고, 온도에 약합니다.

제가 쓰는 다섯 병의 용량이 제각각이라 **어떤 게 들고 다닐 만한지** 직접 비교할 수 있었습니다.

## 용량에 따라 휴대성이 갈립니다

같은 브랜드인데도 **병 모양이 다릅니다.**

```
조말론 30ml    길고 좁음        가방에 들어감
조말론 100ml   넓고 각짐        부피를 차지함
존 바바토스 125ml  라탄이 감싼 병   사실상 불가능
```

**30ml만 휴대가 됩니다.** 폭이 좁아서 파우치에 세워 넣을 수 있습니다. 100ml는 들어가긴 해도 **무겁고 자리를 많이 차지합니다.**

제가 가진 **존 바바토스 125ml 두 병은 아예 못 들고 다닙니다.** 라탄으로 감싼 병이라 부피가 크고, 무엇보다 **그 부피를 감수할 이유가 없습니다** — 지속력이 길어서 다시 뿌릴 일이 거의 없거든요.

```
지속력이 길다  →  들고 다닐 필요가 줄어듭니다
```

**휴대를 고민하게 되는 건 대개 농도가 낮은 향수**입니다. → [향수 부향률 완전정리](/blog/perfume-concentration/)

## 들고 다니는 세 가지 방법

### ① 작은 정품 (30ml 이하)

**가장 간단합니다.** 덜어 담는 수고가 없고 변질 걱정도 적습니다.

다만 **30ml도 매일 들고 다니기에는 무겁습니다.** 유리병이라 떨어뜨리면 깨지고요.

### ② 디캔트 용기에 덜어서 ← 가장 현실적

**5\~10ml 아토마이저**에 덜어 담는 방법입니다. 가볍고, 깨져도 손실이 작습니다.

```
✅ 알루미늄·두꺼운 유리 재질
✅ 5~10ml
❌ 얇은 플라스틱 (알코올에 삭습니다)
```

**덜어 담을 때 주의할 점이 있습니다.**

- **깔때기나 전용 리필 도구**를 쓰세요. 그냥 부으면 많이 흘립니다
- **용기를 먼저 말리세요.** 물기가 남아 있으면 향이 변합니다
- **공기를 많이 넣지 마세요.** 가득 채우는 게 산화가 덜합니다

→ [디캔트(소분) 완전정리](/blog/decant-guide/)

### ③ 고체 향수·향수 종이

**뿌리는 게 아니라 바르거나 문지르는** 형태입니다. 기내 반입이 자유롭고 깨질 일도 없습니다.

다만 **향의 종류가 제한적이고 지속력이 짧습니다.** 쓰던 향수를 그대로 가져가고 싶다면 ②가 맞습니다.

## 기내 반입 — 액체 규정

여행 갈 때 가장 많이 막히는 부분입니다.

```
개별 용기    100ml 이하
전체 합계    1L 투명 지퍼백 1개
```

**용기에 적힌 표기 용량이 기준입니다.** 150ml 병에 30ml만 남아 있어도 **용기가 150ml면 안 됩니다.**

| | 기내 | 위탁 |
| --- | --- | --- |
| 30\~100ml | **가능** (지퍼백에) | 가능 |
| 100ml 초과 | **불가** | 가능 |

**제 125ml 두 병은 기내 반입이 안 됩니다.** 위탁 수하물에 넣어야 하는데, 그러면 **깨질 위험과 온도 변화**를 감수해야 합니다.

> 국가·항공사마다 세부 기준이 다를 수 있습니다. **면세점에서 산 경우**는 밀봉 봉투를 뜯지 않으면 예외가 적용되는 경우가 많습니다.

**여행에는 소분이 답입니다.** 5\~10ml면 규정에 걸릴 일이 없습니다.

## 들고 다닐 때 망가지는 이유

### ① 온도 — 차에 두지 마세요

**가장 흔하고 가장 치명적입니다.**

```
여름 차 안    쉽게 50도를 넘습니다
겨울 차 안    밤새 영하
```

향수는 **열과 온도 변화에 약합니다.** 차에 두면 향이 변하고 색이 진해집니다. "차에 두고 필요할 때 뿌려야지"는 **향수를 가장 빨리 망가뜨리는 방법**입니다.

→ [향수 보관법과 유통기한](/blog/perfume-storage/)

### ② 흔들림

가방 안에서 계속 흔들리면 **공기와 섞이는 면적이 늘어납니다.** 치명적이진 않지만 좋을 것도 없습니다.

**소분 용기를 가득 채워두면** 이 문제가 줄어듭니다.

### ③ 빛

투명한 병은 **직사광선에 약합니다.** 가방 안에 있으면 괜찮지만, 창가나 차 대시보드는 피하세요.

## 밖에서 다시 뿌릴 때

**가장 흔한 실수가 덧뿌리기입니다.**

자기 향은 **20\~30분이면 코가 익숙해져서 안 느껴집니다.** 사라진 게 아니라 못 느끼는 건데, 그걸 모르고 또 뿌리면 **주변에는 두 배로 전달됩니다.**

```
최소 4시간 경과 + 1회
```

이 기준을 넘지 마세요. 그리고 **실내에서 다시 뿌리는 건 피하세요.** 화장실이나 밖에서 하는 게 낫습니다.

→ [향수 뿌리는 위치와 올바른 방법](/blog/how-to-apply-perfume/)

## 정리

```
휴대에 맞는 용량   30ml 이하 · 또는 5~10ml 소분
기내 반입          용기 표기 100ml 이하
차에 두기          절대 금지
다시 뿌리기        4시간 경과 + 1회
```

**지속력이 긴 향수를 쓰면 애초에 들고 다닐 필요가 줄어듭니다.** 제가 125ml 두 병을 들고 다니지 않는 건 부피 때문만이 아니라, **다시 뿌릴 일이 없어서**이기도 합니다.

**매일 들고 다닐 생각이라면 소분이 답입니다.** 정품을 통째로 넣고 다니는 건 무겁고, 깨지고, 변질됩니다.
