향수를 끝까지 써본 분은 아실 텐데, **다 쓰고 나면 병이 애매하게 남습니다.**

유리에 금속 노즐이 박혀 있고, 안에는 향이 남아 있습니다. 그냥 버리기도 그렇고 어디에 넣어야 할지도 모르겠습니다.

저는 **50ml 한 병을 끝까지 썼습니다.** 그때 알아본 것들을 정리했습니다.

## 먼저 — 아직 남아 있습니다

**"안 나온다"와 "비었다"는 다릅니다.**

분사가 안 되기 시작해도 **바닥에 2\~5ml가 남아 있는 경우가 흔합니다.** 펌프가 빨아올리는 관(딥 튜브)이 바닥에 완전히 닿지 않기 때문입니다.

```
분사 안 됨  ≠  비었음
```

### 끝까지 쓰는 방법

**① 기울여서 뿌리기**

가장 간단합니다. 병을 **45도 정도 기울인 채** 노즐을 누르면 남은 액이 관 쪽으로 몰려 몇 번 더 나옵니다.

**② 세워서 하루 두기**

옆으로 눕혀 보관했다면, **똑바로 세워 하루 두면** 액이 바닥에 모여 다시 나오는 경우가 있습니다.

**③ 노즐을 빼고 덜어내기**

진짜 마지막 수단입니다. 분무 캡을 빼면 (브랜드에 따라 안 빠지기도 합니다) **작은 공병이나 디캔트 용기에 옮겨 담을 수 있습니다.**

> ⚠️ **무리해서 빼지 마세요.** 금속 크림프가 단단히 물려 있는 제품이 많고, 억지로 빼다 유리가 깨지면 다칩니다. 안 빠지면 거기까지입니다.

소분 용기와 방법은 [디캔트(소분) 완전정리](/blog/decant-guide/)에 적어뒀습니다.

## 버릴 때 — 분리배출이 애매합니다

**향수병은 그냥 유리로 분류하기 어렵습니다.** 이유는 세 가지입니다.

| 부분 | 문제 |
| --- | --- |
| **노즐·펌프** | 금속과 플라스틱이 섞여 있고 분리가 안 됩니다 |
| **내용물** | 알코올이 남아 있습니다 |
| **유리** | 일반 유리병과 재질이 다른 경우가 있습니다 |

### 현실적인 방법

**완전히 비운 다음**에 처리하는 게 기본입니다.

```
① 남은 액을 최대한 쓴다
② 노즐이 빠지면 → 유리와 금속을 따로
③ 안 빠지면 → 지자체 기준을 확인
```

**지자체마다 기준이 다릅니다.** 분리배출 안내나 주민센터에 문의하시는 게 정확합니다. 일반적으로는 **노즐이 분리되지 않으면 일반쓰레기**로 보는 경우가 많습니다.

> **남은 액을 하수구에 붓지 마세요.** 알코올 농도가 높고 향료가 섞여 있습니다. 소량이라면 **휴지에 흡수시켜** 버리는 쪽이 낫습니다.

### 브랜드 회수 프로그램

**일부 브랜드는 공병을 받습니다.** 매장에 가져가면 회수해 주거나, 리필·할인 혜택을 주는 곳도 있습니다.

브랜드마다 운영 여부가 다르니 **사기 전에 확인해두면** 나중에 편합니다. 매장에서 물어보면 바로 알려줍니다.

## 버리기 전에 — 기록해두면 좋은 것

**이게 이 글에서 가장 쓸모 있는 부분일 수 있습니다.**

병을 버리면 정보도 같이 사라집니다. 다시 사려고 할 때 **"그게 뭐였더라"**가 됩니다.

```
✅ 제품명 전체 (수식어까지)   Artisan 인지 Artisan Pure 인지
✅ 부향률 표기               EDT / EDP / Cologne
✅ 용량                     30 / 50 / 100ml
✅ 바닥의 배치 코드           제조 시기 확인용
```

**사진 한 장이면 끝납니다.** 라벨과 바닥을 찍어두세요.

### 다 쓴 느낌도 같이 적어두세요

저는 블랙베리 앤 베이 50ml를 끝까지 쓰고 나서 **몇 가지를 알게 됐습니다.**

```
질리지 않았다          →  매일 안 뿌려서
지속력이 짧은 게 단점인 줄 알았는데  →  그래서 안 질렸다
다시 살 생각은 있는데   →  남은 병이 많아 미루는 중
```

**한 병을 끝까지 써야만 알 수 있는 것들**입니다. 몇 번 뿌려보고는 절대 안 나옵니다. → [블랙베리 앤 베이 리뷰](/blog/jo-malone-blackberry-bay/)

**다음에 뭘 살지 정하는 데 이 기록이 가장 정확합니다.**

## 공병을 남겨두는 경우

버리지 않고 두는 분들도 있습니다. 이유가 있습니다.

| 용도 | 설명 |
| --- | --- |
| **서랍·옷장** | 뚜껑을 열어두면 남은 향이 몇 달 갑니다 |
| 장식 | 조말론처럼 병 디자인이 좋은 경우 |
| 교환·AS | 하자 문의 시 배치 코드가 필요할 수 있습니다 |

**첫 번째가 실용적입니다.** 바닥에 남은 양으로는 뿌릴 수 없어도, **닫힌 공간에서 은근하게 퍼지기에는 충분합니다.**

## 정리

```
① 분사가 안 돼도 2~5ml 남아 있습니다     기울여서 뿌려보세요
② 노즐이 안 빠지면 무리하지 마세요        깨지면 다칩니다
③ 완전히 비운 뒤 지자체 기준대로          대개 노즐 분리 여부가 기준
④ 버리기 전에 라벨과 바닥을 찍어두세요     다시 살 때 필요합니다
```

**④를 권합니다.** 저도 다 쓰고 나서야 "이 향수에 대해 알게 된 것"을 적어둘 걸 그랬다고 생각했습니다. 병이 비는 순간이 **그 향수를 가장 잘 아는 시점**인데, 그냥 버리면 그대로 사라집니다.
